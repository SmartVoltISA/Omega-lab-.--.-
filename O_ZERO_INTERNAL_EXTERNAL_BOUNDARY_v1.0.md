# Ω-0 — Internal / External Boundary Principle v1.0

## Status

**FOUNDATIONAL RESEARCH PRINCIPLE — CANONICAL EXTENSION OF Ω-0**

This document extends the Ω-0 Boundary / Reference Principle to the distinction between an internal domain and an external domain. It does not change the typed Ω-Math core.

## 1. Boundary defines inside and outside

A boundary is not merely a line separating two pre-existing regions. In the Ω research interpretation, the selected boundary provides the reference relative to which **inside** and **outside** are defined.

Conceptual form:

```text
                 EXTERNAL
                    ↓
          ───────── 0 ─────────
                    ↑
                 INTERNAL
```

Therefore:

> **Internal and external are relational descriptions relative to a selected boundary.**

## 2. 0 as the interaction frontier

When an internal system encounters an external process, `0` may represent the current frontier at which the two domains interact.

```text
EXTERNAL  →  [ 0 ]  →  INTERNAL
               ↑
          interaction front
```

The frontier may transmit, reject, transform, or reflect interactions. The specific mechanism must be declared by the model.

## 3. External pressure versus internal response

For models involving opposition or competition, the frontier may be interpreted as the location at which **external influence and internal response meet**.

```text
external influence
        ↓
        0  ← frontier
        ↑
 internal response
```

The word *struggle* is retained only as a model-specific interpretation. It is not a primitive of Ω-Math.

## 4. Dynamic boundary

If the frontier changes with time:

```text
t₀:   EXTERNAL | 0₀ | INTERNAL
t₁:   EXTERNAL   | 0₁ | INTERNAL
t₂:   EXTERNAL     | 0₂ | INTERNAL
```

then the changing boundary describes how the internal/external configuration evolves.

This provides a candidate bridge:

`external influence → boundary interaction → internal response → boundary change → new internal/external configuration`

## 5. Boundary as reference

The same `0` reference can be used to describe deviation:

```text
              0
              │
       ┌──────┴──────┐
      −1             +1
```

Thus the Ω-0 concept has two compatible uses:

1. **reference between opposing directions/states**;
2. **frontier between internal and external domains**.

These uses must not be conflated with a third relation value.

## 6. Relation to path and time

If a system's interaction frontier evolves through time, its ordered history can be represented conceptually as:

`0(t₀) → 0(t₁) → 0(t₂) → ...`

This supports the research hypothesis that a dynamic path may be understood as the time-ordered history of changing boundaries/fronts.

For competitive systems, this may be interpreted as **struggle through time**.

This remains a hypothesis about a class of models, not a universal definition of `PATH`.

## 7. Preservation of Ω-Math typing

This principle does not modify:

`EntityState = {0,1}`

`RelationState = {−1,+1}`

and does not permit:

`RelationState = {−1,0,+1}`

The boundary/reference meaning of `0` is a higher-level research concept. It is not encoded by inserting a zero-valued relation.

In particular:

`absence ≠ 0`

`boundary ≠ relation`

`boundary ≠ entity`

## 8. Research classification

**OBSERVATION:** Ω-Lab contains a recurring line of work on boundaries, zero, interaction, internal/external separation, feedback and system organization.

**INTERPRETATION:** A boundary can be treated as an interaction frontier between an internal domain and an external domain.

**HYPOTHESIS:** The dynamics of this frontier may provide a compact description of system persistence, adaptation, feedback, memory and structural change.

**STATUS:** OPEN / CANONICAL RESEARCH DIRECTION.

No universal physical claim is made here.

## 9. Canonical statement

> **Ω-0 Internal / External Boundary Principle:** `0` may serve as the reference/frontier separating and connecting an internal domain and an external domain. External influence and internal response meet at this frontier. If the frontier evolves through time, its ordered evolution provides a candidate dynamic description of a path; in competitive models this may be interpreted as struggle through time.

Future experiments may confirm, refine or reject this formulation without deleting its historical record.
