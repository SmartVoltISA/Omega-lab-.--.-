# Ω-Lab Methodology

## Цель

Цель методологии Ω-Lab — проверять, даёт ли анализ через отношения дополнительную информацию по сравнению с обычными способами представления системы.

Ω-Lab не предполагает заранее, что relation-first подход лучше.

Это экспериментальный вопрос.

## Базовый эксперимент

### 1. Исходная система

Определить:

- данные;
- элементы;
- наблюдения;
- известные связи;
- временной интервал;
- ограничения.

### 2. Базовый метод

Проанализировать систему существующим стандартным методом.

Результат сохранить.

### 3. Relation-first представление

Представить ту же систему через отношения.

Явно указать:

- тип отношения;
- направление;
- интенсивность, если она используется;
- временную зависимость;
- правила изменения отношений.

### 4. Ω-анализ

Исследовать:

- конфигурации;
- кластеры;
- петли;
- устойчивость;
- переходы;
- потенциально возникающие структуры.

### 5. Сравнение

Сравнить Ω с базовым методом.

Основной вопрос:

> Даёт ли Ω дополнительную информацию?

## Контрольные эксперименты

По возможности использовать:

- случайные данные;
- перемешанные связи;
- шум;
- удаление части отношений;
- изменение начальных условий;
- альтернативные модели;
- повторные запуски.

## Воспроизводимость

Для эксперимента необходимо сохранять:

- исходные данные;
- код;
- параметры;
- seed;
- версию модели;
- дату эксперимента;
- результаты;
- интерпретацию.

## Отрицательные результаты

Отрицательный результат является полноценным результатом.

Если Ω не показывает преимущества, это необходимо зафиксировать.

Если структура исчезает после изменения условий, это также необходимо зафиксировать.

## Главный критерий

Ω-Lab полезен только в том случае, если его применение позволяет:

- увидеть дополнительную структуру;
- получить новую проверяемую гипотезу;
- упростить анализ;
- обнаружить зависимость, которую трудно увидеть другим способом;
- или получить иной практически полезный взгляд на систему.

Красивой визуализации недостаточно.
