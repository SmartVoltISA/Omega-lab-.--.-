# Ω Hypothesis Note — State / Frame / Update

Date: 2026-08-13
Status: HYPOTHESIS / NOT A RESULT

## Current formulation

A proposed analogy is a continuously observed process as a sequence of states/frames:

`S0 -> S1 -> S2 -> S3 -> ...`

The analogy suggests that what is experienced as continuous evolution might, at a deeper model level, be represented as repeated state updates. A film is a useful intuition: individual frames are distinct, while rapid ordered replacement produces the appearance of continuity.

## Proposed physical hypothesis

The hypothesis to test is NOT "light speed equals frame rate" as a statement of fact. The stronger proposal is:

> There may exist a fundamental update mechanism for physical states, with a maximum update/causal-reconfiguration rate. The observed invariant c might emerge from a relation between an update rate and a characteristic spatial scale.

Dimensional requirement:

`c = L_update * f_update`

where `f_update` has units 1/time and `L_update` has units length. Without an independently derived `L_update`, an update frequency alone cannot equal c.

## Information interpretation

A state update can be interpreted as a reconfiguration of relations. The hypothesis therefore distinguishes:

- information as distinguishable state/relationship structure;
- memory as retained dependence on prior state;
- time as ordering or parameterization of transitions;
- update rate as a possible property of the transition mechanism.

These are not identified as the same entity without tests.

## Important correction

The phrase "light propagation is destruction of information" is retained only as a hypothesis. Standard physics does not imply that light propagation is intrinsically information destruction. The experiment must define what information is preserved, transformed, lost, or redistributed before using that language.

## Falsification targets

1. A model in which continuous-time dynamics reproduce all tested observations without a discrete update scale weakens the update-frame hypothesis.
2. A model in which the observed invariant c cannot be represented as `L_update * f_update` with independently motivated L_update weakens the identification of c with an update limit.
3. If Lorentz invariance and causal structure require no underlying update clock, the hypothesis remains unnecessary even if a discrete simulation can imitate it.
4. If information can propagate/transform without irreversible destruction in the relevant physical model, the "light = destruction" interpretation fails.

## Next experimental direction

Do not start by assuming c is a frame rate. Construct minimal discrete-update models and continuous-time controls, then test whether the same observable causal structure can be generated. Only after that should any relationship between c, update rate, and characteristic length be evaluated.

## Scientific status

No physical result is claimed by this note. It is a structured hypothesis and a list of falsification conditions.
