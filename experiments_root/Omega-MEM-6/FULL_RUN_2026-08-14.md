# Ω-MEM-6 — Full multi-seed run

**Date:** 2026-08-14
**Status:** PRELIMINARY / multi-seed replication

## Run

30 seeds, N=20,000 symbols per generator. The pilot was replicated across seeds 0–29 using the same current-only, relevant-context, and capacity-matched random-memory constructions.

## Mean conditional entropy H(X_next | context), bits

| Generator | Current only | Relevant memory | Random memory |
|---|---:|---:|---:|
| Periodic-4 | 0.5000 | 0.0000 | 0.4999 |
| Markov-2 | 0.6666 | 0.0000 | 0.6665 |
| Thue-Morse | 0.9183 | 0.6666 | 0.9181 |
| IID | 0.9999 | — | 0.9997 |

## Observation

The multi-seed replication preserves the pilot pattern: relevant context reduces next-transition uncertainty for the structured generators, while a capacity-matched random memory does not. IID remains effectively unpredictable from the tested memory.

## Interpretation boundary

This is evidence for predictive information carried by the tested context representation. It is **not** evidence for causality, agency, or a universal law of memory. The constructions remain deliberately simple and require an independent audit before a final Ω-MEM-6 conclusion.

## Required next control

The next run must explicitly measure predictive-partition cardinality/entropy and perform a memory-only intervention while holding the current external observation fixed. The intervention must alter internal context without altering the emitted/current symbol.
