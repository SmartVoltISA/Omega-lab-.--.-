## Provenance defect discovered

The archived `run_r2.py` does NOT implement bootstrap confidence intervals. It calculates only mean, sample SD, min and max. Therefore the RESULTS.md claims of 10,000-resample bootstrap 95% CIs are not outputs of the archived executable.

The code also does not archive per-seed rows to a separate machine-readable file; it writes them into the JSON output. That is sufficient for later recomputation, but no separate independent-recomputation script is present in the archived experiment.

The claimed exact-output SHA-256 values and the statement that a second exact execution was performed cannot be independently established from the archived code alone. They must therefore be treated as **unverified provenance claims** until raw output files and an execution record are archived.
