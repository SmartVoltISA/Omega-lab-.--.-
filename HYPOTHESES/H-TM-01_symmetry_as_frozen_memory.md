# H-TM-01 — Symmetry as Frozen Memory, Asymmetry as Temporal Direction

**Status:** OPEN / UNTESTED
**Date:** 2026-08-10
**Domain:** Ω-TM (Time–Memory)

## Hypothesis

A symmetric configuration can be treated as a **frozen memory imprint**: it preserves a configuration but contains no intrinsic directional distinction between alternative temporal orientations.

An asymmetry between configurations introduces a distinguishable direction: it allows the system to distinguish one configuration from another and potentially reconstruct an ordering such as before → after.

Working formulation:

> **Symmetry is a frozen imprint of memory; asymmetry is the distinguishable direction through which temporal order can be recovered.**

This is a hypothesis about the minimal formal structure of Ω-Lab, **not a claim about physical time or the physical universe**.

## Motivation

The Ω-0 experiment suggested that an internally updated trace can generate distinguishable order without explicitly supplying a physical time coordinate. The next question is whether memory and temporal direction can be represented as two aspects of the same underlying distinction.

The current intuition is:

```text
symmetric configuration
        ↓
   frozen imprint
        ↓
   no direction

symmetry breaking / asymmetry
        ↓
   distinguishable states
        ↓
   directional relation
        ↓
   recoverable order (before → after)
```

## What must be tested

The hypothesis must survive controls showing that:

1. A symmetric state can preserve information without itself specifying a direction.
2. A controlled asymmetry makes configurations distinguishable.
3. The asymmetry can carry information about the preceding configuration rather than being mere random noise.
4. A sequence of preserved asymmetries permits recovery of an ordering relation.
5. Removing the relevant trace destroys or measurably reduces the ability to reconstruct that ordering.
6. The observed effect is not produced solely by an externally supplied clock, hidden history buffer, arbitrary threshold, or manually selected parameter.

## Falsification conditions

This hypothesis should be considered weakened or rejected if any of the following is demonstrated:

- directional order can be recovered with no persistent distinguishable trace;
- the same directional information appears in a matched random/asymmetric null model;
- asymmetry does not improve reconstruction of prior state or order;
- the apparent temporal direction is entirely an artifact of externally supplied iteration/time indices;
- a simpler model reproduces the result without the proposed memory/asymmetry mechanism.

## Experimental status

**No confirmation yet.**

Ω-0 provides motivation for this hypothesis, but does not test it directly. Ω-TM experiments must be run before assigning any stronger status.

```text
act → trace → update
```

## Important distinction

This document does **not** assert:

- that physical time is an illusion;
- that the universe is fundamentally symmetric;
- that memory is literally identical to time;
- that asymmetry necessarily creates physical time.

It records a falsifiable working hypothesis for the Ω-Lab research program.
