# Ω-Lab — FOUNDATION ENTRY PROTOCOL v1.0

**Status:** CORE / READ FIRST

This is the entry rule for every new chat, agent, organ, experiment and continuation.

## 1. First read the foundation

Before planning, coding, experimenting or interpreting:

**FOUNDATION → PLAN → WORK/HISTORY → ARCHIVE**

No later layer may override the foundation without an explicit foundational revision.

## 2. Foundation is fixed on the stone

The foundation is the source of structural rules. It is not rewritten to fit a current task.

Core:

**MEMORY + BIDIRECTIONAL TRANSFORMATION**

**РАЗНОЕ → СВЯЗИ → ЦЕЛОЕ → FEEDBACK → РАЗНОЕ**

**ОПОРА → УЗЕЛ → СВЯЗЬ → РЕБРО → ГРАФ → ЦЕЛОЕ**

See `OMEGA_FOUNDATION_ARCHITECTURE_v1.1.md`.

## 3. History is memory

History is preserved through three memory layers:

### ACTIVE
Current operational state used by the next action.

### PASSIVE
Completed, paused, rejected or inactive material that remains directly retrievable and must not be forgotten.

### ARCHIVE
Historical records preserved as evidence of what actually happened; not silently rewritten.

Flow:

**ACTIVE ↔ PASSIVE → ARCHIVE**

Movement between layers is a state transition, not deletion.

## 4. Historical rule

Preserve:

**what was → what was done → what happened → what was verified → what changed → why → what follows**

Errors, failures, incomplete work and frozen projects remain part of history.

Rework creates a new version. It does not erase the old one.

## 5. Entry obligation

Any new participant must read the foundation before using the plan or history. Any continuation must preserve the chain of provenance.

**FOUNDATION FIRST. HISTORY ALWAYS.**
