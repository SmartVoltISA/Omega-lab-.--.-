# Ω-Lab — Open Review Structure

The public archive is separated from public scientific participation.

## Immutable source layer

`01_HISTORY/CHAT_ARCHIVES/`

Contains historical chat archives. External participants have no write access to this layer.

## Open review layer

`02_OPEN_REVIEW/`

Suggested sections:

- `QUESTIONS/`
- `CRITICISM/`
- `SUPPORT/`
- `REPLICATIONS/`
- `REFUTATIONS/`
- `CORRECTIONS/`
- `ALTERNATIVE_INTERPRETATIONS/`

Every review record should reference the archive, claim, experiment, or commit it concerns.

## Experiments layer

`03_EXPERIMENTS/`

Suggested sections:

- `PROTOCOLS/`
- `CODE/`
- `DATA/`
- `RESULTS/`
- `REPRODUCTIONS/`

## Conclusions layer

`04_STATUS/`

Suggested status categories:

- `CONFIRMED/`
- `SUPPORTED/`
- `OPEN/`
- `UNCONFIRMED/`
- `REFUTED/`
- `SUPERSEDED/`

A status document does not alter the historical source. It records the current assessment based on later evidence.

## Core rule

> Anyone may challenge the record. Nobody outside the authorized archive maintainers may rewrite the record itself.
