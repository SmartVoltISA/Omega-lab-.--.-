## Coordinate-context rule

Before counting or comparing a property, declare the measurement context:

```text
WHAT is measured
    ↓
IN WHICH dimension / plane / axis
    ↓
FROM WHICH reference / coordinate frame
    ↓
AT WHICH position / state
    ↓
AT WHICH time / index
    ↓
RESULT
```

A projection is an observation in a specified context, not automatically the whole system.

## Cross-scale research hypothesis

Different systems may exhibit analogous structural invariants despite different physical mechanisms. Candidate comparison classes include molecular structures, astrophysical systems, networks, oscillatory processes, and biological life histories.

The analogy must never be promoted to physical identity merely because a picture looks similar. The experimental question is whether an explicitly defined invariant survives changes of scale, coordinate frame, projection, and mechanism.

## Mandatory safeguards

- `0 as boundary/reference` ≠ `0 as relation value`
- absence ≠ `0`
- projection ≠ whole system
- mathematical multidimensionality ≠ proof of a specific physical cosmology
- structural analogy ≠ physical identity
- visual similarity ≠ invariant
- time index ≠ automatically physical duration
