# BIDIRECTIONAL MAPPING + GOAL-DIRECTED SEARCH v1.0

Status: Ω-LAB METHODOLOGY

## Three modes

### DISCOVERY
`relations → structures → entities → invariants → properties`

### PHYSICAL ABSTRACTION
`observations → measurements → properties → relations → structure → invariants → candidate entity`

### GOAL-DIRECTED
`goal → constraints → structural search → candidate → test`

## Blindness rule

Generation must not receive the conventional physical name of the desired solution when the purpose is to discover structure independently.

## Bidirectional test

Compare:

`Ω-generated signature`

against

`physical-derived signature`.

Convergence is a correspondence result. It is not by itself proof of physical ontology.

## Goal representation

Represent goals as measurable or computable requirements such as stability, switching, recovery, selectivity, coupling, capacity, propagation, robustness or cost. Search over structures satisfying the requirements.

## Unknowns

No adequate known physical match → `OPEN` / `HYPOTHESIS`, subject to testability. Never treat absence of a known match as proof of a new entity.

## Required controls

Null models, complexity-matched alternatives, perturbation tests, invariance tests and blind comparisons where feasible.

## Canonical loop

`FACT → CHECK → RESULT → DECISION → FIXATION`

combined with:

`PHYSICS ↔ Ω`

and:

`GOAL → Ω → PHYSICAL TEST`.
