# Ω-MATH v0.1 — Математика через сущности, состояния и элементарные изменения

## Статус документа

**Тип:** фундаментальная спецификация исследовательского языка Ω-MATH.

**Статус:** начальный этап / OPEN.

**Принцип:** этот документ не заменяет классическую математику и не объявляет её неверной. Классическая математика рассматривается как уже развитая и проверенная система знаний. Задача Ω-MATH — построить рядом с ней другой способ записи и понимания математических объектов и операций, начиная с минимального набора сущностей.

**Главная идея:** человек сначала фиксирует состояние, затем различает изменение состояния и может описывать это изменение элементарными шагами. Базовые направленные изменения принимаются как `+1` и `−1`.

Документ является живым. Каждая новая операция, определение, теорема, доказательство, эксперимент, контрпример и обнаруженная граница языка должны добавляться сюда или в связанные документы. Новое знание не удаляет старую версию: история сохраняется.

# 1. Зачем существует Ω-MATH

Классическая математика обычно преподаётся как набор чисел, формул, правил и теорем. Ω-MATH ставит другой вопрос:

> Из каких минимальных действий можно последовательно построить математическое описание количества, изменения, отношения, структуры и пространства?

Цель не в том, чтобы сделать математику «проще любой ценой». Цель — сделать **механику математического мышления видимой**.

Ω-MATH должна отвечать на четыре вопроса для каждого нового понятия:

1. **Что является сущностью?**
2. **В каком состоянии она находится?**
3. **Какая операция переводит её из одного состояния в другое?**
4. **Какие отношения и законы следуют из этих операций?**

---

# 2. Минимальный словарь

## 2.1 Состояние

Пусть `x` — математическая сущность, имеющая некоторое состояние.

Запись:

`x = n`

означает, что состояние `x` равно значению `n`.

## 2.2 Ноль

`0` — числовое состояние, соответствующее отсутствию единиц в счёте.

В классической теории множеств:

`|∅| = 0`.

В Ω-MATH ноль дополнительно рассматривается как **опорное состояние**, относительно которого можно определять положительное и отрицательное направление изменения.

## 2.3 Единица

`1` — одна единица количества или один элементарный шаг.

Базовая связь:

`0 + 1 = 1`.

## 2.4 Элементарные изменения

`+1` — один шаг в положительном направлении.

`−1` — один шаг в отрицательном направлении.

Они образуют базовую пару направленных преобразований:

`x --(+1)--> x+1`

`x --(−1)--> x−1`.

Важно: `+1` и `−1` — не «два предмета». Это операции изменения состояния на одну единицу.

---

# 3. Первый фундаментальный цикл

Для любого целого состояния `x` вводятся два перехода:

`S+(x) = x + 1`

`S−(x) = x − 1`.

Основное взаимное свойство:

`S−(S+(x)) = x`

и

`S+(S−(x)) = x`.

То есть один шаг вперёд и один шаг назад взаимно компенсируются.

Это первая элементарная форма обратимости.

---

# 4. Построение натурального ряда

Начинаем с:

`0`.

Применяем `+1`:

`0 → 1 → 2 → 3 → 4 → ...`

Формально:

`S(n) = n + 1`.

Тогда:

`S(0)=1`

`S(1)=2`

`S(2)=3`

и вообще:

`S(n)=n+1`.

Натуральный ряд может быть определён через начальное состояние и операцию следующего элемента. Это связывает Ω-MATH с классическим подходом Пеано.

---

# 5. Счёт

Пусть существует конечное множество элементов:

`A = {a1, a2, ..., an}`.

Его количество обозначается:

`|A| = n`.

Счёт можно представить как последовательное присвоение номеров:

`a1 → 1`

`a2 → 2`

`...`

`an → n`.

Таким образом, количество — это результат установления соответствия между элементами и начальными фрагментами натурального ряда.

---

# 6. Пустота, существование и различение

Минимальная схема:

`∅` — нет элементов.

`{A}` — существует один элемент.

`{A,B}` — существуют два различимых элемента, если `A ≠ B`.

Ключевое различие:

- **сущность** отвечает на вопрос «что рассматривается?»;
- **равенство** отвечает «это одно и то же или нет?»;
- **количество** отвечает «сколько различимых элементов?».

Ω-MATH не утверждает, что «различение» заменяет аксиоматическую теорию множеств. Это рабочая операционная интерпретация, которая должна быть сопоставлена с классическими основаниями.

---

# 7. Сложение

Сложение объединяет количества или последовательно применяет шаг `+1`.

Для натурального `a`:

`a + 0 = a`.

`a + (b+1) = (a+b)+1`.

Отсюда:

`a+1` — один элементарный положительный шаг.

`a+2 = (a+1)+1`.

`a+3 = ((a+1)+1)+1`.

Пример:

`2+3 = (((2+1)+1)+1)=5`.

То есть сложение можно реализовать как повторное применение `+1`.

## Основные классические свойства

Коммутативность:

`a+b=b+a`.

Ассоциативность:

`(a+b)+c=a+(b+c)`.

Нейтральный элемент:

`a+0=0+a=a`.

---

# 8. Вычитание

Вычитание — движение в отрицательном направлении или поиск такого состояния `x`, для которого:

`x+b=a`.

Если решение существует, то:

`x=a-b`.

Через элементарные шаги:

`5−1=4`

`5−2=3`

`5−5=0`.

На целых числах:

`a−b = a + (−b)`.

Основная компенсация:

`(a+b)−b=a`.

---

# 9. Целые числа

Натуральных чисел недостаточно, если требуется выполнить `2−5`.

Расширение:

`Z = {...,−3,−2,−1,0,1,2,3,...}`.

В Ω-MATH целое число можно понимать как результат относительно нулевого состояния и последовательности направленных шагов.

Например:

`+3 = 0 → +1 → +1 → +1`.

`−3 = 0 → −1 → −1 → −1`.

Расстояние от нуля:

`|−3|=|+3|=3`.

Знак определяет направление; модуль — величину удаления от нуля.

---

# 10. Умножение

Умножение может быть построено как повторное сложение.

`a×b` означает добавление `a` к себе `b` раз для натурального `b`.

Рекурсивно:

`a×0=0`.

`a×(b+1)=a×b+a`.

Пример:

`3×4=3+3+3+3=12`.

## Классические свойства

Коммутативность:

`ab=ba`.

Ассоциативность:

`(ab)c=a(bc)`.

Единица:

`a×1=a`.

Ноль:

`a×0=0`.

Дистрибутивность:

`a(b+c)=ab+ac`.

---

# 11. Деление

Деление связано с обратным действием умножения.

`a/b=c` тогда и только тогда, когда:

`a=bc`,

при условии `b ≠ 0`.

Деление может отвечать на два разных вопроса:

1. сколько групп размера `b` содержится в `a`;
2. какова величина одной части при разбиении `a` на `b` равных частей.

Деление на ноль в обычной арифметике не определено.

---

# 12. Рациональные числа

Если целых чисел недостаточно для точного результата деления, вводятся дроби:

`Q = {a/b : a,b∈Z, b≠0}`.

Например:

`1/2`, `3/4`, `−7/5`.

Дробь представляет отношение двух целых чисел.

Эквивалентность:

`a/b = c/d` тогда и только тогда, когда `ad=bc` при ненулевых знаменателях.

---

# 13. Действительные числа

Рациональные числа не заполняют всю числовую прямую. Например, уравнение:

`x²=2`

не имеет рационального решения.

Действительные числа `R` расширяют числовую систему так, чтобы такие величины существовали.

`√2` определяется условиями:

`x²=2`, `x>0`.

Действительная числовая система связана с понятием полноты: всякая непустая ограниченная сверху часть `R` имеет точную верхнюю грань.

---

# 14. Комплексные числа

В действительных числах нет решения:

`x²+1=0`.

Вводится:

`i²=−1`.

Комплексное число:

`z=a+bi`.

Сложение:

`(a+bi)+(c+di)=(a+c)+(b+d)i`.

Умножение:

`(a+bi)(c+di)=(ac−bd)+(ad+bc)i`.

Комплексные числа образуют алгебраически замкнутое поле.

---

# 15. Отношения

Математическая сущность может быть связана с другой сущностью отношением.

Примеры:

`a=b`

`a≠b`

`a<b`

`a>b`

`a∈A`

`a⊂A`.

Отношения могут обладать свойствами:

- рефлексивность;
- симметричность;
- антисимметричность;
- транзитивность.

Комбинации этих свойств порождают эквивалентности, порядки и другие структуры.

---

# 16. Функция

Функция — правило, которое каждому допустимому входу ставит в соответствие единственный выход.

`f:X→Y`.

Запись:

`y=f(x)`.

Функция — это преобразование состояния:

`x → f(x)`.

Композиция:

`(g∘f)(x)=g(f(x))`.

Тождественная функция:

`id(x)=x`.

Обратная функция существует, если преобразование является обратимым на соответствующих областях.

---

# 17. Уравнение

Уравнение утверждает равенство двух выражений:

`F(x)=G(x)`.

Решение — значение `x`, при котором равенство истинно.

Решение уравнения можно рассматривать как поиск состояния, являющегося фиксированной точкой отношения равенства.

Пример:

`x+3=5`.

Применяем обратное преобразование `−3` к обеим сторонам:

`x+3−3=5−3`.

Получаем:

`x=2`.

---

# 18. Неравенства

Вместо равенства рассматривается порядок:

`x<y`, `x≤y`, `x>y`, `x≥y`.

Операции должны сохранять или предсказуемо изменять порядок.

Например, при умножении неравенства на положительное число направление сохраняется; при умножении на отрицательное — меняется.

---

# 19. Степень

Для натурального `n`:

`a^n = a×a×...×a` (`n` множителей).

Рекурсивно:

`a^0=1` для стандартной алгебры при ненулевом `a`.

`a^(n+1)=a^n×a`.

Законы:

`a^m a^n=a^(m+n)`.

`(a^m)^n=a^(mn)`.

`(ab)^n=a^n b^n` в коммутативной арифметике.

---

# 20. Корень

Корень — обратная операция к степени в соответствующем смысле.

`√a` — неотрицательное число, квадрат которого равен `a`, если такое действительное число существует.

Обобщение:

`x^n=a`.

---

# 21. Последовательность

Последовательность — функция натурального аргумента:

`a:N→X`.

Запись:

`a₀,a₁,a₂,...`.

Рекурсия позволяет задавать состояние через предыдущее:

`a_(n+1)=F(a_n)`.

Это непосредственно связывает Ω-MATH с динамикой состояний.

---

# 22. Предел

Предел описывает поведение величины при приближении аргумента к определённому состоянию или при росте индекса.

`lim(x→a) f(x)=L`.

Строгое определение для действительных функций выражается через `ε-δ`:

для каждого `ε>0` существует `δ>0`, такое что из `0<|x−a|<δ` следует `|f(x)−L|<ε`.

Предел — не обязательно значение функции в точке. Это описание поведения вокруг точки.

---

# 23. Производная

Производная измеряет локальную скорость изменения.

`f'(x)=lim(h→0) [f(x+h)−f(x)]/h`.

В Ω-интерпретации это переход от конечного изменения к предельной локальной структуре изменения.

Физически производная положения по времени даёт скорость:

`v=dx/dt`.

---

# 24. Интеграл

Определённый интеграл может быть построен как предел сумм малых вкладов.

`∫_a^b f(x)dx`.

В простейшей интерпретации — накопленный результат непрерывного суммирования.

Фундаментальная теорема анализа связывает интегрирование и дифференцирование:

`d/dx ∫_a^x f(t)dt = f(x)`

при стандартных условиях.

---

# 25. Ряды

Ряд — сумма членов последовательности:

`Σ a_n`.

Сходимость определяется существованием конечного предела частичных сумм:

`S_N=Σ_(n=0)^N a_n`.

Если `S_N→S`, ряд сходится к `S`.

---

# 26. Векторы

Вектор содержит величину и структуру направления в соответствующем пространстве.

`v=(v₁,...,v_n)`.

Сложение:

`u+v=(u₁+v₁,...,u_n+v_n)`.

Умножение на скаляр:

`λv=(λv₁,...,λv_n)`.

Линейная комбинация:

`a₁v₁+...+a_nv_n`.

---

# 27. Матрицы и линейные преобразования

Матрица может представлять преобразование между конечномерными координатными представлениями.

`y=Ax`.

Композиция линейных преобразований соответствует умножению матриц.

Определитель характеризует, среди прочего, изменение ориентированного объёма и обратимость квадратной матрицы:

`det(A)≠0` ⇔ `A` обратима.

Собственные значения определяются:

`Av=λv`, `v≠0`.

---

# 28. Геометрия

Геометрия вводит объекты, точки, линии, поверхности, расстояния, углы и преобразования.

Евклидово расстояние:

`d(x,y)=√Σ_i(x_i−y_i)²`.

Пифагор:

`a²+b²=c²` для прямоугольного треугольника.

Тригонометрия связывает углы и отношения длин.

---

# 29. Вероятность

Вероятностная модель задаётся пространством исходов `Ω`, событиями и вероятностной мерой `P`.

Основные свойства:

`0≤P(A)≤1`.

`P(Ω)=1`.

Для несовместимых событий:

`P(A∪B)=P(A)+P(B)`.

Условная вероятность:

`P(A|B)=P(A∩B)/P(B)` при `P(B)>0`.

Независимость:

`P(A∩B)=P(A)P(B)`.

---

# 30. Статистика

Статистика строит описание и выводы о данных.

Среднее:

`x̄=(1/n)Σx_i`.

Дисперсия описывает разброс относительно среднего.

Математическое ожидание:

`E[X]`.

Статистическая модель связывает наблюдаемые данные с неизвестными параметрами и предположениями.

---

# 31. Логика

Логика описывает отношения между высказываниями.

Основные операции:

`¬A` — отрицание.

`A∧B` — конъюнкция.

`A∨B` — дизъюнкция.

`A⇒B` — импликация.

`A⇔B` — эквивалентность.

Кванторы:

`∀x` — для всех `x`.

`∃x` — существует `x`.

Доказательство строит цепочку допустимых переходов от аксиом и уже доказанных утверждений к заключению.

---

# 32. Теория множеств

Множество — фундаментальный объект современной классической математики.

Основные операции:

`A∪B` — объединение.

`A∩B` — пересечение.

`A\B` — разность.

`A×B` — декартово произведение.

`A⊆B` — включение.

Мощность множества обозначается `|A|`.

Для бесконечных множеств возникают разные мощности и теория кардинальных чисел.

---

# 33. Алгебраические структуры

## Группа

Множество с бинарной операцией, обладающей ассоциативностью, нейтральным элементом и обратным элементом для каждого элемента.

## Кольцо

Структура с двумя операциями, аналогичными сложению и умножению, удовлетворяющими соответствующим аксиомам.

## Поле

Коммутативное кольцо с единицей, в котором каждый ненулевой элемент имеет мультипликативную обратную.

`Q`, `R` и `C` являются полями.

---

# 34. Топология и пространство

Топология изучает свойства, сохраняющиеся при непрерывных деформациях.

Метрическое пространство задаётся множеством `X` и функцией расстояния:

`d:X×X→R`.

Требуются:

`d(x,y)≥0`;

`d(x,y)=0 ⇔ x=y`;

`d(x,y)=d(y,x)`;

`d(x,z)≤d(x,y)+d(y,z)`.

Последнее — неравенство треугольника.

---

# 35. Дифференциальные уравнения и динамика

Дифференциальное уравнение связывает состояние и его изменение.

Пример:

`dx/dt=f(x,t)`.

Это непосредственно соответствует общей Ω-схеме:

`состояние → правило изменения → новое состояние`.

Дискретный аналог:

`x_(n+1)=F(x_n)`.

Таким образом, непрерывная и дискретная динамика становятся естественными областями для дальнейшего развития Ω-MATH.

---

# 36. Дискретная математика

Включает:

- комбинаторику;
- графы;
- деревья;
- рекуррентные отношения;
- конечные автоматы;
- алгоритмы;
- булеву алгебру;
- теорию кодов;
- теорию информации.

Граф:

`G=(V,E)`.

`V` — множество вершин.

`E` — множество связей между вершинами.

Это особенно важно для Ω, поскольку отношения могут быть представлены графовой структурой.

# 37. Оптимизация

Задача оптимизации ищет допустимое состояние, максимизирующее или минимизирующее целевую функцию:

`min f(x)`

или

`max f(x)`.

При наличии ограничений:

`g_i(x)≤0`, `h_j(x)=0`.

Ω-MATH должна в будущем описывать оптимизацию как поиск состояния по правилу сравнения и изменения.

---

# 38. Теория чисел

Исследует свойства целых чисел:

- делимость;
- простые числа;
- разложение на множители;
- НОД и НОК;
- сравнения по модулю;
- диофантовы уравнения.

Алгоритм Евклида:

`gcd(a,b)=gcd(b,a mod b)`.

Он является примером конечной последовательности преобразований, сохраняющей инвариант результата.

---

# 39. Инвариант

Инвариант — величина или свойство, которое не изменяется при заданном преобразовании.

Если преобразование `T` действует на состояние `x`, то инвариант `I` удовлетворяет:

`I(T(x))=I(x)`.

Это один из ключевых мостов между операцией и теоремой.

---

# 40. Теорема

Теорема — утверждение, выведенное из аксиом, определений и ранее доказанных результатов посредством допустимого доказательства.

Структура:

`аксиомы + определения + леммы → доказательство → теорема`.

Следствие — утверждение, непосредственно получаемое из уже доказанного результата.

Контрпример показывает, что универсальное утверждение ложно.

---

# 41. Что такое «полностью» в Ω-MATH

«Полностью» не означает, что в одном файле должны находиться все доказательства всей существующей математики.

Это означает, что архитектура должна иметь место для каждого класса математических объектов и отношений, а новые результаты должны добавляться последовательно.

Поэтому Ω-MATH строится слоями:

`примитивы → определения → операции → свойства → леммы → теоремы → следствия → приложения`.

---

# 42. Базовая Ω-модель

На текущем этапе минимальный рабочий набор:

1. **Сущность** — то, о чём говорится.
2. **Состояние** — текущее значение сущности.
3. **Различение** — установление того, одинаковы сущности или различны.
4. **+1** — элементарное положительное изменение.
5. **−1** — элементарное отрицательное изменение.
6. **Композиция** — последовательное применение операций.
7. **Обратимость** — возможность компенсировать изменение.
8. **Отношение** — связь между сущностями или состояниями.
9. **Инвариант** — сохраняемое свойство.
10. **Правило** — определённый способ перехода.

Пока это не считается достаточным основанием всей математики. Это стартовая гипотеза архитектуры.

# 43. Первые Ω-формулы

## Закон 1 — Нулевой сдвиг

`x + 0 = x`.

Добавление нулевого количества не меняет состояние.

## Закон 2 — Единичный сдвиг

`x + 1 = S+(x)`.

## Закон 3 — Обратный единичный сдвиг

`x − 1 = S−(x)`.

## Закон 4 — Компенсация

`(x+1)−1=x`.

`(x−1)+1=x`.

## Закон 5 — Многократный шаг

`x+n = S+^n(x)` для натурального `n`.

## Закон 6 — Многократный обратный шаг

`x−n = S−^n(x)`.

## Закон 7 — Сложение как композиция шагов

`x+(m+n)=(x+m)+n`.

## Закон 8 — Симметрия направлений

Положительное и отрицательное направления являются взаимно компенсирующими операциями.

---

# 44. Важнейшее различие: число и операция

`1` и `+1` не являются одним и тем же.

`1` — значение / единичное количество.

`+1` — операция изменения на единицу.

Аналогично:

`−1` может обозначать отрицательное число, а в записи `x−1` — величину отрицательного единичного сдвига.

Контекст должен различать объект и операцию.

Это различение является обязательным для дальнейшей формализации языка.

---

# 45. Вторая фундаментальная схема Ω

Для любой допустимой операции `T`:

`состояние x → T → состояние y`.

Если существует операция `T⁻¹`, такая что:

`T⁻¹(T(x))=x`,

то преобразование обратимо.

Для базового шага:

`T=+1`, `T⁻¹=−1`.

Это даёт простейший пример обратимого преобразования.

---

# 46. Третья фундаментальная схема — композиция

Если:

`x → A → y`

и

`y → B → z`,

то:

`x → B∘A → z`.

Композиция является одним из центральных механизмов построения сложных операций из простых.

Например:

`+1,+1,+1`

эквивалентно:

`+3`.

---

# 47. Ω-MATH и классическая математика

Классическая математика сохраняется как нормативная система определений, аксиом, теорем и доказательств.

Ω-MATH рассматривает её как большую область, которую постепенно нужно описывать через собственный язык.

Принцип соответствия:

`Ω-описание → классическое выражение → проверка эквивалентности`.

Если соответствие установлено, результат фиксируется.

Если соответствие пока не установлено, запись получает статус `OPEN`.

Никакие новые Ω-утверждения не должны автоматически считаться доказанными классическими теоремами.

---

# 48. Статусы знаний Ω-MATH

Каждый новый результат получает один из статусов:

- `DEFINED` — определено;
- `DERIVED` — выведено из уже принятых правил;
- `PROVED` — доказано формально;
- `EQUIVALENT` — показано соответствие классическому результату;
- `EXPERIMENTAL` — получено вычислительным или конструктивным экспериментом;
- `CONJECTURE` — предположение;
- `COUNTEREXAMPLE` — найден контрпример;
- `OPEN` — вопрос пока не решён.

# 49. Правило накопления знаний

Ω-MATH является развивающейся системой.

Каждая новая единица знания должна записываться по схеме:

`ВОПРОС → ОПРЕДЕЛЕНИЕ → ПРАВИЛО → ВЫВОД → ПРОВЕРКА → СТАТУС → СВЯЗИ`.

Для теорем:

`ФОРМУЛИРОВКА → УСЛОВИЯ → ДОКАЗАТЕЛЬСТВО → СЛЕДСТВИЯ → КОНТРПРИМЕРЫ/ОГРАНИЧЕНИЯ → СТАТУС`.

Для экспериментов:

`ГИПОТЕЗА → ПАРАМЕТРЫ → МЕТОД → РЕЗУЛЬТАТ → ПРОВЕРКА → ИНТЕРПРЕТАЦИЯ`.

История не удаляется.

# 51. Главный принцип текущей версии

Ω-MATH начинается не с утверждения «мы уже знаем новую математику».

Она начинается с более скромного утверждения:

> **Мы начинаем строить язык математики снизу вверх, используя минимальные сущности и операции, и будем добавлять знания по мере их получения.**

`+1` и `−1` являются первым рабочим примером направленного изменения.

`0` является опорным состоянием.

`1` является единичным количеством.

`состояние → операция → новое состояние` является базовой динамической схемой.

`отношение` связывает сущности.

`композиция` строит сложные операции.

`инвариант` показывает, что сохраняется.

`доказательство` устанавливает необходимость вывода.

Это только начало пути.

# Заключение

Классическая математика уже является огромным зданием.

Ω-MATH не пытается снести это здание.

Она начинает строить **лестницу к нему снизу**.

Первый шаг:

`0`

Второй:

`1`

Третий:

`+1 / −1`

Затем:

`состояние → изменение → последовательность → количество → отношение → операция → правило → структура → пространство → изменение → доказательство`.

Каждый следующий шаг должен быть добавлен, определён, связан с предыдущими и проверен.

**Мы пока идём в темноте. Поэтому каждый найденный шаг становится светом для следующего.**
