# Ω-P0 — Отношение прежде пути

**Статус:** рабочий принцип / OPEN

## Формулировка

> **Сначала отношение → потом путь.**

Расширенная рабочая формулировка:

> **Отношение задаёт возможность изменения. Изменение реализует направление. Последовательность изменений образует путь.**

## Связанная гипотеза

> **Изменение отношений порождает путь.**

Эта формулировка сохранена как гипотеза, которую необходимо проверить, а не как установленный универсальный закон.

## Рабочая схема

`отношение → изменение → след → последовательность изменений → путь`

Возможное продолжение:

`путь → изменение отношений → новый путь`

что даёт потенциальный цикл:

`отношение → изменение → путь → след → изменение отношения → новый путь → ...`

## Контекст возникновения

Принцип сформирован на пересечении архивов Ω-Lab, особенно линий:
- различие → связь → структура;
- отношения → устойчивые структуры;
- след → память;
- структура → следующий уровень отношений;
- поиск закона изменения отношений.

Особенно важными источниками являются архивы 019, 020 и 021.

## Важное ограничение

Нельзя автоматически трактовать `−1, 0, +1` только как начало, середину и конец временного пути. В реляционной плоскости `−1` и `+1` должны оставаться сторонами отношения; конкретный путь возникает при реализации изменения/направления.

## Что проверить

1. Можно ли строго определить «отношение» без заранее заданного пути.
2. Можно ли определить изменение отношения без скрытого времени.
3. Можно ли вывести путь как последовательность изменений, а не постулировать его.
4. Остаётся ли эта схема справедливой в Ω-CA и других моделях.
5. Может ли путь обратно изменять отношения.
6. Если да, возникает ли устойчивый рекурсивный цикл.
7. Можно ли получить `−1,0,+1` из этого механизма, а не задавать их заранее.

## Архивная граница

Пока это **рабочий принцип Ω-Lab**, а не доказанная теорема.
