# Ω-Lab — ENTITY → PROPERTY → LAW → MEASURE → UNIT

Status: FOUNDATIONAL METHODOLOGY v1.0

## Why this exists

Ω-Lab must distinguish the structures it discovers from the physical names humans may later assign to them.

The working correction is:

`structure → candidate entity → invariant → property → interaction/law → physical correspondence → measurement → unit`

Never begin with a desired physical label and fit the structure to it.

## Layer separation

The structural/mental model may contain distinctions, relations, boundaries, states, transitions, memory, order and models without containing physical time or physical units.

The physical layer is separate. Communication between layers is a hypothesis/measurement problem, not an assumption.

Therefore an ordered sequence

`A ≺ B ≺ C`

does not imply seconds exist inside the model.

## Entity candidate

Search for:

`bounded relational structure + persistence/invariant + distinguishability`.

A candidate is not promoted merely because it resembles a known physical object.

Test:

- distinguishability;
- boundary/accessibility;
- internal relations;
- persistence under admissible transformations;
- identity-preserving invariant;
- interaction while retaining traceability.

## Property and law

Keep separate:

`entity ≠ property ≠ relation ≠ law`.

A property must be operationally measurable within a declared domain. A law requires a validated relation among declared quantities.

Never promote a correlation to causality or a mathematical relation to a physical law without the appropriate evidence.

## Unit rule

`second`, `metre`, `kilogram` and analogous units are measurement standards, not automatically fundamental entities.

Therefore:

`duration ≠ second`

`length ≠ metre`

`mass ≠ kilogram`.

A dimensionless structural result cannot be reported as a physical dimensional quantity merely by attaching a unit name.

## Time rule

Ω-Lab may test structural succession, transition counts, recurrence, relative rates, characteristic intervals and irreversible order.

These are not automatically physical duration.

Required bridge:

`structural event → physical event correspondence → reproducible physical interval → measurement procedure → unit`.

## Experimental procedure

For any proposed physical correspondence:

1. Define the structural object without the physical label.
2. Define competing interpretations, including null interpretation.
3. Specify the observable mapping.
4. Pre-register the metric and acceptance/rejection criteria.
5. Execute controls and countermodels.
6. Search actively for falsification.
7. Report what is structurally demonstrated separately from what is physically interpreted.
8. Promote only evidence-backed correspondences.

## Required language

Use:

`FACT → CHECK → RESULT → DECISION → FIXATION`.

And distinguish:

`UNKNOWN ≠ TRUE`

`HYPOTHESIS ≠ EXPERIMENT`

`RESULT ≠ CONCLUSION`

`CONCLUSION ≠ PROOF`.

## Entity discovery target

A dedicated future Ω-Lab program may enumerate small typed relational systems and search for:

`boundary → stable substructure → invariant → identity → interaction → emergent property`.

Physical names must be assigned only after this blind structural stage.

## Core rule

> Do not ask the structure to produce the human unit. Ask the structure to reveal stable entities and properties first; then test how those properties couple to the physical layer; only then define measurement and units.
