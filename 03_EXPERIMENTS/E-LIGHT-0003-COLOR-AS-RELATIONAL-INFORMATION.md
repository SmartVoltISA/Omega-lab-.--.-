# E-LIGHT-0003 — Color as relational information

## Question
Can optical state (wavelength/color) act as a carrier of relational information rather than merely as an output label?

## Working hypothesis
A connection can carry state/information. Optical excitation can alter the state of a connection; wavelength can encode distinguishable states, and the receiving system can transform that state into its own internal state.

## Important distinction
Color is not assumed to be a fundamental physical memory variable. Here it is an observable label for spectral state. The experiment tests whether spectral state can preserve and transfer relational information.

## Model
Two nodes A and B, coupled by a connection. The connection has an internal state s and a spectral label lambda.
Input states: red-like (R), green-like (G), blue-like (B).
The optical interaction changes the receiver state according to resonance/selection rules, not by an explicitly hard-coded 'divide' operation.

## Controls
1. No optical input.
2. Optical input with non-resonant wavelength.
3. Resonant optical input with one spectral state.
4. Resonant optical input with a second distinguishable spectral state.
5. Same optical energy, different wavelength.

## Predicted discriminating result
If wavelength is only energy magnitude, equal-energy inputs should produce equivalent receiver states.
If spectral state carries relational information through the interaction, different wavelengths can produce distinguishable receiver states even when total optical energy is controlled.

## External physical grounding
Experiments with quantum dots have demonstrated transfer of photonic quantum information into internal electronic spin states; the photonic state can be encoded in distinguishable optical colors/frequencies. This supports the physical plausibility of treating optical state as an information-bearing relation, without proving the Omega model. APS Physics, 'Linking Two Quantum Dots with Single Photons' (2017).

## Status
Exploratory. The model result must not be treated as evidence for a universal three-color law. The next implementation should use explicit resonance/transition rules and fixed energy controls.

## Current interpretation
Color may be treated as a visible projection of relational state. The key object remains the relation and its transformation, not the color itself.
