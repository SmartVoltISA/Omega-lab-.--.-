# SmartVolt Protection Standard

Version: 1.0 — 2026

## 1. Purpose

This repository is part of the SmartVoltISA project family. This standard defines baseline repository protection, provenance, and licensing rules.

## 2. Licensing

- Repository-level license: Apache License 2.0 unless this repository explicitly declares another license.
- Root LICENSE is the canonical repository license file.
- Existing file-specific and third-party licenses remain valid and must not be silently replaced.
- Preserve required copyright and attribution notices.

## 3. Security

- Do not commit secrets, credentials, private keys, or sensitive personal data.
- Security vulnerabilities should be reported privately.
- Security fixes must preserve traceability.

## 4. Provenance

- Preserve authorship, origin, history, and applicable notices.
- Do not silently replace or erase license information.

## 5. Exceptions

A file or directory may use another license when that license is explicitly declared and compatible with the repository's documented policy.

## 6. Verification

Repository protection should be checked by automated audit before release or major integration.
