# Ω-INDEX — адресный язык графа

**Status:** ACTIVE / ARCHITECTURE
**Purpose:** единый индекс узлов, связей и графов Ω для навигации человеком и машиной.

## Основной принцип

Архив не переписывается. Ω-INDEX создаётся как адресный слой поверх существующей истории.

Каждый значимый объект получает:

- `Ω-ID` — постоянный идентификатор;
- `TYPE` — NODE / EDGE / GRAPH / SOURCE / RESULT;
- `STATUS` — текущее состояние;
- `WEIGHT` — сила/надёжность связи или элемента;
- `SOURCE` — происхождение;
- `PARENT` / `CHILDREN` — структурные связи;
- `FORWARD LINKS` / `BACK LINKS` — направление связей;
- `INPUT / ACTION / RESULT / FEEDBACK` — жизненный цикл;
- `VERSION / DATE / HISTORY` — история.

## Статусы

| Маркер | Status | Значение |
|---|---|---|
| ⚪ | UNKNOWN | недостаточно информации |
| 🔵 | OBSERVED | наблюдалось |
| 🟡 | HYPOTHESIS | рабочее предположение |
| 🟠 | TESTING | проверяется |
| 🟢 | VERIFIED | проверено |
| 🟩 | WORKS | подтверждено практическим результатом |
| 🔴 | FAILED | проверено и не работает |
| 🟣 | REWORK | требует доработки |
| ⚫ | ARCHIVED | исторический материал |

Цвет — визуальное представление статуса для человека. Машина использует буквенный `STATUS`.

## Вес

`WEIGHT` не заменяет `STATUS`.

Статус отвечает на вопрос **«что сейчас известно о состоянии?»**.
Вес отвечает на вопрос **«насколько сильна/устойчива эта связь или опора?»**.

Вес нельзя назначать произвольно: он должен иметь основание в источниках, повторных проверках и практических результатах.

## Обратная связь обязательна

Ω-граф является живым только при наличии обратного контура:

```text
SOURCE
  ↓
NODE
  ↓
EDGE
  ↓
GRAPH
  ↓
ACTION / TEST
  ↓
RESULT
  ↓
STATUS / WEIGHT
  ↓
FEEDBACK
  ↓
NODE / EDGE UPDATE
  ↓
NEW GRAPH STATE
```

У значимого объекта должна существовать обратная трасса происхождения: **результат → связь → узел → граф → источник**.

Forward и Back links являются обязательными для значимых связей.

## Человек + машина

Индекс должен быть читаем человеком без открытия всей истории и однозначно адресуем машиной.

Пример:

```text
Ω-LIGHTNING-001
🟢 VERIFIED
TYPE: GRAPH
SOURCE: Ω-SPEC-1

E → I → T → N → C/R
```

## Правило внедрения

Сначала индексируются крупные графы и ключевые узлы. После проверки удобства и корректности система масштабируется на архив.

Не переписывать историю ради индекса. Индекс указывает на историю, а не заменяет её.
