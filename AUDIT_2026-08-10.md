# Ω-Lab — Full Research Audit

**Audit date:** 2026-08-10

## Purpose

This audit consolidates the current Ω-Lab state using the repository, the current Ω-Lab research history available in the working context, and the latest Ω-MEM experiments. It is intended to prevent loss of scientific history and to separate established observations from interpretations and hypotheses.

## Repository audit

The repository already contains the core methodology, hypothesis registry, Ω-B experiments, Ω-0/time-memory work, Ω-MEM-1a–1d, Ω-MEM-2 and the Ω-MEM-3 protocol. The main gap was that the latest Ω-MEM-3 execution/results and the methodological corrections identified after it were not yet represented as a complete, reproducible research record.

## Global research rules

1. Do not delete scientific history.
2. Preserve failed methods, artifacts, counterexamples, old versions, parameters, seeds, code and results.
3. Separate **OBSERVATION / INTERPRETATION / HYPOTHESIS / EVIDENCE / COUNTEREVIDENCE**.
4. Do not turn a visualization or a single simulation into a mechanism claim.
5. Fix metrics and decision criteria before inspecting results whenever possible.
6. Use negative controls and matched null models.
7. Distinguish state size from structural suitability and expressive capacity.
8. Treat a failure of a hand-designed architecture as evidence about that architecture first, not automatically about the underlying process.
9. A result is not a proof of a physical claim unless independently justified outside the model.
10. Every hypothesis status must preserve its previous status and the experiment that changed it.

## Ω-0 methodological correction

The Ω-0 program runs inside an externally sequential computation (`for` loop). Therefore it does not demonstrate emergence of physical time from absolute nothing. The defensible claim is narrower:

> An internally distinguishable order can be produced without an explicit physical-time variable when an act reads and updates a retained trace.

The original `can_determine_order = diversity > 1 and predictable` criterion is insufficient to establish absolute temporal position or temporal direction. Future experiments must distinguish local order, phase, absolute position and temporal direction.

## Ω-MEM-1 methodological correction

The earliest prediction test was partly tautological because the predictor was trained on the deterministic machine state/output mapping. Accuracy of a deterministic machine does not by itself prove that memory is useful for prediction. The stronger Ω-MEM-1a–1d intervention experiments are therefore more important evidence.

Lifetime values capped at 50 must be interpreted as **at least 50**, not exactly 50. Decay values capped at 20 must be interpreted as **at least 20**, not exact decay times.

The first strict intervention test produced 0/5 differences because the intervention construction collapsed the compared systems to the same post-reset state. That test is retained as a failed method, not evidence against memory.

## Ω-MEM-3 methodological correction

### P2

The previous generator called `Markov-2` actually depended only on the immediately previous symbol. It is therefore a first-order Markov process. Ω-MEM-4 must either rename it or, preferably, implement a true second-order process based on `(X[t-1], X[t])`.

### P4

The previous "matched HMM estimator" used a two-state rule `X -> 0`, `Y -> 1`. This is effectively last-observation context, not a genuine Bayesian belief filter. The near identity of Matched and Context performance confirms this limitation. Ω-MEM-4 must implement a real hidden-state process and a genuine belief-state representation.

### P3

The Ω-MEM-3 result shows that the tested parity tracker was insufficient. It does **not** by itself establish that Thue–Morse requires O(log n) memory. The minimum expressive requirement remains unknown and must be measured.

### Matched architecture

"Matched" was hand-designed separately for each process. Therefore the experiment mixes structural correspondence and architectural quality. Ω-MEM-4 must explicitly separate **MATCH** from **EXPRESSIVENESS** and control memory size.

## Ω-B historical status

Ω-B investigated self-organizing/internal dynamics versus noise. Controls exposed dependence on diffusion rules and an architectural artifact. The original "self-will" interpretation is not established. B1–B4 remain preliminary until code, seeds and raw data are archived; B5 spatial-shuffle control remains relevant. These negative/limiting results are part of the scientific history and must not be deleted.

## Ω-MEM research direction

The current research question is no longer simply "does memory help?" It is:

> How are memory size, memory structure and expressive capacity related to the amount of information about the future that can be retained and used causally?

The immediate test is Ω-MEM-4: **EXPRESSIVENESS × STRUCTURAL MATCH**.

## Required next controls

- Same S, different architectures.
- Same architecture, different S.
- True Markov-2.
- Genuine HMM with Bayesian/discretized belief state.
- Thue–Morse expressive-capacity sweep.
- Conditional entropy `H(next | state)`.
- Paired seed comparisons and confidence intervals.
- Strict intervention with identical future input after reset.
- Random-iid negative control.
- Known positive control such as Periodic-4.

## Repository policy

The repository is the authoritative scientific archive. Chat messages are working notes. Every completed experiment should add its protocol, code, data/results, report and graph artifacts where practical, and update the hypothesis graph without deleting previous evidence.
