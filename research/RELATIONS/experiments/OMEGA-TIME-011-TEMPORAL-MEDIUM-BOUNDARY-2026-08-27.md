# OMEGA-TIME-011 — Temporal-medium boundary

Date: 2026-08-27
Status: EXPERIMENTAL / MODEL RESULT; PHYSICAL INTERPRETATION OPEN

## Hypothesis under test
Treat a common causal evolution coordinate lambda as the Universe/system flow. Let local dynamical state control how readily a subsystem changes per unit lambda. Test one process crossing three regimes: free/high-activity, transition, bound/low-activity.

This is a model of the proposed gas/liquid/crystal analogy, NOT evidence that physical time is literally a material fluid or has thermodynamic phases.

## Model
1D medium, 300 sites:
- sites 0..119: free regime, transition probability p=0.90 per global update;
- sites 120..179: graded transition p=0.90 -> 0.08;
- sites 180..299: bound regime, p=0.08.

A probe attempts one forward spatial transition per global causal update. Its local rate is controlled only by the medium state. No local clock is supplied to the probe.

For a geometric waiting process, expected global updates per successful transition are 1/p. Therefore expected traversal cost is sum(1/p_i).

## Results
Free region (120 transitions): expected cost ≈ 133.33 global updates.
Transition region (60 transitions): expected cost ≈ 183.2 global updates (profile-dependent).
Bound region (120 transitions): expected cost = 1500 global updates.

For equal-length free vs bound regions, the same probe is expected to advance 11.25x more slowly in the bound regime: (1/0.08)/(1/0.90)=11.25.

The trajectory remains ordered and causal throughout. What changes is the local rate of state-transition accumulation relative to the common evolution coordinate.

## Controls
A. Uniform-medium control: if p is constant everywhere, no boundary slowdown occurs.
B. Label-swap control: renaming regimes changes nothing; only transition law p matters.
C. Common-rescaling control: reparameterizing lambda globally does not remove the relative free/bound rate ratio.
D. Equal-dynamics control: if all three regimes are assigned the same p, the effect vanishes.

## Interpretation
PASS: a single globally ordered evolution can coexist with different local rates of internal change. A process crossing into a more constrained region slows relative to processes remaining in a freer region, without changing event order.

This supports a mathematically coherent distinction between:
- common causal flow/order;
- local clock/process rate;
- observed speed.

It does NOT establish that fundamental physical time itself has gas/liquid/crystal states. The exact same observations can be generated by ordinary state-dependent dynamics occurring in one common time parameter. Thus the current experiment cannot distinguish 'time changes state' from 'matter/process dynamics change rate'.

## Strong discriminator required next
Construct two co-located clocks/processes with radically different internal mechanisms. If entering the same region multiplies BOTH rates by the same factor while preserving their ratio, that behaves like a shared local time-rate modification. If each mechanism changes differently, the effect is medium/process dynamics rather than a universal temporal field.

## Current status

H2: Universal local temporal-rate field — OPEN.
H3: Time is literally fluid with gas/liquid/crystal phases — NOT ESTABLISHED.
