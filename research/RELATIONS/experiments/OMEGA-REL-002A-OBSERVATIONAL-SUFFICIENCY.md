# Ω-REL-002A — Observational Sufficiency

Date: 2026-08-13
Status: PROTOCOL — NOT EXECUTED

## Question

Is the observable state of a minimal relation sufficient to determine its future behavior, or can two relations with the same observable relation state evolve differently under identical subsequent conditions?

## Motivation

Ω-REL-001 established the two-component baseline:

`R_obs = (r_AB, r_BA)`

with a temporary qualitative alphabet `{−, 0, +}`. It also showed that quantities computed from the pair are derived rather than independent.

The next question is stronger:

> Can an additional relational degree of freedom emerge from the existing dynamics without being explicitly inserted?

## Core test

For two observations at times `t1` and `t2`, require:

`R_obs(t1) = R_obs(t2)`

while all externally controlled inputs for the subsequent test interval are identical.

Then compare future trajectories:

`Future(t1)` versus `Future(t2)`.

A candidate hidden relational state exists only if:

1. the observed relation states are identical;
2. node states and relevant external conditions are controlled or matched;
3. subsequent inputs are identical;
4. future behavior differs reproducibly;
5. the difference cannot be explained by an already represented state variable or stochastic randomness.

## Important control

Do NOT add a memory variable, hidden mode, internal edge state, or other extra degree of freedom before the test.

The purpose is specifically to determine whether such a degree of freedom is generated by the existing dynamics.

## Preferred implementation

Use an existing relation-level Ω model rather than inventing a new ontology. The current REL-002/003 family provides an existing dynamic relation-weight model and therefore is a suitable candidate source, subject to checking its exact state variables before execution.

## Measurements

For each relation/state observation record:

- observable relation state;
- node/end states;
- external input;
- random seed / stochastic context;
- next-step and multi-step future trajectory;
- whether two matched observations diverge.

Use exact state matching where possible. If continuous weights prevent exact matching, define a pre-registered tolerance and perform a tolerance sweep.

## Falsification

### Supports two-component sufficiency

No reproducible future divergence is found among matched observable states after controlling all represented variables and inputs.

### Challenges two-component sufficiency

Matched observable states repeatedly produce different future behavior under identical conditions, and the difference cannot be attributed to noise, node state, input mismatch, or another existing variable.

## Interpretation constraint

A positive result does NOT immediately mean "memory".

It means only that the current observable relation description is insufficient to predict future behavior. The missing degree of freedom must then be investigated separately.
