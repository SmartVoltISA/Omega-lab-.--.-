# Ω — RELATIONS / EDGES

Status: **RESEARCH AREA / HYPOTHESES ONLY**

This branch of Ω-Lab studies relations (edges) as objects with potentially measurable properties, rather than treating an edge as a featureless connection between nodes.

## Central question

What properties must a relation possess for a network of states to have structure, stability, memory, propagation and change?

## Initial hypothesis

An edge may have more information than mere existence. Candidate properties include:

- existence / absence;
- direction;
- length / distance;
- cross-sectional area;
- thickness;
- volume;
- weight / strength;
- stiffness / resistance to deformation;
- elasticity / recoverability;
- density;
- persistence / lifetime;
- capacity / bandwidth;
- energy cost of creation;
- energy cost of modification;
- energy cost of destruction;
- orientation / anisotropy;
- propagation delay;
- state of the relation itself.

None of these is assumed to be fundamental. Each must survive a minimality test.

## Two-column ontology

| Nodes / states | Relations / edges |
|---|---|
| state | strength |
| distinguishability | stiffness |
| value | length |
| change | direction |
| memory | thickness / area / volume |
| position | density |
| internal state | persistence |
| | propagation rate |
| | energy cost |

This is a working research table, not an established ontology.

## Direction-dependent resistance

A key hypothesis is that the cost of changing or breaking a relation may depend on direction relative to its internal structure:

`E_parallel != E_perpendicular`

The tree/fiber analogy motivates this as a candidate property, but the physical analogy is not itself evidence for an abstract Ω edge.

## Relation → node question

We will explicitly test whether nodes are primary and edges secondary, or whether stable nodes can emerge from persistent patterns of relations. The statement "relations produce nodes" is therefore a hypothesis, not a premise.

## Structure / unstructure

We will distinguish:

1. a graph with edges but no edge state;
2. a weighted graph;
3. a graph with geometric edge properties;
4. a graph whose edges have internal states;
5. a dynamic graph where edge creation/destruction has a cost.

The goal is to determine the minimum edge description that reproduces observed behavior.

## Research order

1. One edge, two nodes.
2. Add one candidate edge property at a time.
3. Test whether the property changes observable behavior.
4. Test whether the property is independent of existing properties.
5. Two edges / three nodes.
6. Competing paths and alternative routes.
7. Networks and maximum degree.
8. Dynamic creation, modification and destruction of edges.
9. Propagation through the network.
10. Only then consider physical analogies and mappings.

## Non-negotiable Ω rule

Do not assign physical meaning to an abstract edge parameter merely because a similar word exists in physics. First define an operational measurement in the model.

Example: "strength" is not a valid parameter until we specify what measurable response defines it.

## Experimental principle

For every candidate property P:

`model without P → model with P → compare behavior → attempt to remove P again.`

If P can be removed without loss under the declared criterion, P is not minimal for that model.

If removing P changes the behavior in a reproducible way, P becomes a candidate necessary property within that model.

## Current status

No edge property is declared fundamental. This directory is a research map for future falsifiable experiments.
