# Ω-RELATIONS — CONSOLIDATED RESEARCH ARCHIVE 037–046

Date: 2026-08-13
Status: ARCHIVE / methodological record

## Purpose

Consolidated record of the recent relation experiments. This archive preserves the sequence of hypotheses, corrections, and results without retroactively rewriting earlier experiments.

## Core methodological correction

The central object is the relation itself:

`A ───── B`

It must not be replaced by a time-series encoding of endpoint changes merely because that encoding is convenient. Binary encodings such as `00, 01, 10, 11` describe changes of endpoint states and are a control representation, not a definition of relation.

Likewise `-1, 0, +1` must not be assumed to be fundamental relation types merely because they are convenient numerical labels.

## REL-037 — Effective number of states

Finite deterministic systems can use fewer recurrent states than the total state space. Increasing the available state space does not produce a universal finite maximum number of states. This means that counting states alone does not identify a fundamental number of relations.

## REL-038 — Generators of transformations

The investigation shifted from counting states to asking how transformations are generated compositionally. This is a mathematical control layer, not yet an ontology of Ω-relations.

## REL-039 — Generator correction

An earlier claim that two generators suffice for the full transformation monoid was corrected. For finite sets with N>=3, a suitable generating set requires at least three generators in the tested framework.

## REL-040 — Generator minimality

For the tested finite transformation spaces:

N=2: minimum 2 generators.
N=3: minimum 3 generators.
N=4: minimum 3 generators.

This is a result about a chosen mathematical transformation space, not a claim about fundamental Ω-relations.

## REL-041 — Removing generators

For N=3, a working triple of transformation types generates all 27 transformations; removing individual generators reduces the reachable set.

For N=4, the complete triple generates all 256 transformations. Removing the irreversible merge leaves the permutation group (24 transformations); removing other generators produces smaller closed sets.

Conclusion: the tested transformation roles are operationally independent in that model.

## REL-042 — Properties of transformation roles

The generator roles can be described observationally by properties such as reversibility, preservation/destruction of distinguishability, locality and global rearrangement. These are properties of operations, not automatically properties of the relation itself.

## REL-043 — Reversible structure

The reversible sector requires more than one generator for N>=3. Specific generator names are not fundamental; the important observable distinction is between reversible transformations and transformations that destroy distinctions.

## REL-044 — Distinguishability control

If one records only whether A=B or A!=B, four local transition types appear: 00, 01, 10, 11. This is a useful binary control model but does not replace the original relation object.

A three-way ordering `A<B`, `A=B`, `A>B` requires additional structure such as an order; it cannot be derived from bare equality/difference alone.

## REL-045 — Relation-derived quantitative difference

A quantitative difference can emerge from relational organization, e.g. path length in a connected structure, rather than being primitive. This supports treating numerical magnitude as potentially derived rather than automatically fundamental.

## REL-046 — Local relation without metric

Removing numerical magnitude leaves only structural relational transitions. The four binary distinguishability transitions are not equivalent to the original relation taxonomy. Therefore binaryization must not be mistaken for discovery of new relation types.

## Final methodological conclusion

The recent branch did NOT prove that Ω has 3, 4, 27, or any other fixed number of fundamental relations.

What it did establish is more useful:

1. Counting encoded states is not the same as counting relations.
2. Endpoint time changes are not the relation itself.
3. Numerical labels such as -1, 0, +1 must remain hypotheses/labels until their operational origin is established.
4. Reversible and irreversible transformations are observably different in the tested mathematical model.
5. A relation must be studied directly through operations that act on the relation itself.
6. Any proposed property must be observable, operationally defined, measurable, and tested for independence.

## Current Ω research direction

Return to the primitive object:

`A ───── B`

Do not encode it prematurely.

Find the minimal operation that can distinguish one relation from another while holding the endpoints and external conditions controlled.

Only after observable differences appear should a property name be assigned.

## Important correction to preserve

The binary experiment is not a failed version of the relation experiment. It is a control representation. It may reveal useful mathematics, but it must not be allowed to redefine the object under investigation.
