# Ω-REL-001 — Independent Relation Components

Date: 2026-08-13
Status: HYPOTHESIS / RESEARCH PROTOCOL — NOT EXECUTED

## Research question

For the minimal relation between two distinguishable states A and B, is the relation completely described by the two observable directional responses:

`R = (r_AB, r_BA)`

or is an additional independently variable component required?

## Current minimal model

`A ─── B`

We temporarily describe each directional response by a qualitative alphabet:

`r ∈ {−, 0, +}`

This alphabet is a modeling assumption to be tested separately. It is not declared fundamental.

If two independent directional components are sufficient, the qualitative interaction state space contains:

`3² = 9`

combinations.

These nine states must not be interpreted as nine fundamental relation types. They are states of the current two-component, three-valued model.

## Important distinction

`00` must NOT automatically be identified with absence of a relation.

A relation may exist while producing zero observable response in both directions under a particular intervention. Existence and response must therefore remain separate variables.

## Third-component question

A notation such as `++-` does not by itself establish a three-component relation.

A third component is justified only if there exists an observable quantity `r3` such that:

1. two relations can have identical `r_AB` and `r_BA`;
2. they differ in `r3`;
3. the difference in `r3` produces a reproducible observable difference;
4. `r3` cannot be reconstructed as a function of `r_AB` and `r_BA`;
5. the effect survives controls and independent runs.

If instead:

`r3 = f(r_AB, r_BA)`

then `r3` is derived, not an independent component.

## Candidate interpretations of a third component

A third component could represent, for example:

- an internal state of the relation;
- history dependence;
- a hidden but operationally observable relational variable;
- another independent mode of interaction.

These are hypotheses only. No interpretation is accepted before measurement.

## Falsification logic

The two-component hypothesis is strengthened if every observable behavior of the tested minimal relation can be reproduced using `(r_AB, r_BA)` and no additional independent variable is required.

It is weakened if two relations with identical `(r_AB, r_BA)` produce reproducibly different future behavior and the difference cannot be reduced to node state, intervention history already represented in the model, implementation artifacts, or another existing variable.

## Scope

Do not introduce:

- networks;
- geometry;
- physical force;
- stiffness;
- energy;
- memory as a predefined property;
- node emergence;
- classical graph structure;

unless required later by a controlled extension.

The first target is only the component count of the minimal relation.

## Required protocol

1. Define the minimal observable response precisely.
2. Establish the two-component baseline.
3. Enumerate the 9 qualitative states of the `{−,0,+}²` model.
4. Search for observationally distinct states that share the same pair `(r_AB,r_BA)`.
5. Introduce a candidate third variable only when such a distinction is observed or theoretically required by an already declared observable.
6. Test whether the candidate third variable is reducible to the first two.
7. Repeat across independent runs/seeds where stochasticity exists.

## Current conclusion

No experimental result is claimed.

Current working hypothesis:

`R = (r_AB, r_BA)`

is the minimal interaction representation for a relation between two distinguishable states, with the number of independent components still unresolved.

`Execution not verified. No experimental result claimed.`
