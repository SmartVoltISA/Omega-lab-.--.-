## 1. New observation / hypothesis

A new structural interpretation has been proposed for the ENERGY branch:

> **Relations and structures may contain a stored energetic potential, while restructuring or destruction can release that potential or require an energetic expenditure.**

The important distinction is between two modes:

```text
ENERGY
├── STORED / BOUND / STRUCTURAL
│      ↓
│   potential for change
│
└── RELEASED / TRANSFERRED / DYNAMIC
       ↓
    change of state over an ordered process
```

This is currently a hypothesis. The words "stored" and "released" are operational placeholders until a minimal model defines them without importing classical energy by assumption.

---

## 2. Proposed two-mode distinction

### E-MODE-A — Structural / stored energy

A relation or structure has a configuration that constrains possible future transformations.

The hypothesis is that the configuration itself may encode a **potential for transformation**.

Analogy only:

```text
[stable structure]
      │
      │ contains potential
      ↓
[possible restructuring]
```

The "battery" analogy is useful intuitively but is not yet a physical definition.

The key research question is:

> Can a static structure possess a measurable quantity that predicts or constrains the transformations available to it, even before the transformation occurs?

### E-MODE-B — Released / transferred energy

When the structure changes, the stored potential may become an active transfer or redistribution associated with the transition.

Conceptual form:

```text
STRUCTURAL POTENTIAL
        ↓
     RELEASE
        ↓
RELATIONAL CHANGE
        ↓
NEW STATE
```

The important point is that the release is not being defined merely as "energy moving through time". The experiment must determine whether an ordered sequence of state changes is required to operationally describe the release.

# 3. Third possibility that must remain open

The two-mode model must not be forced into a binary too early.

A third possibility is:

```text
STRUCTURAL ENERGY
      ↕
TRANSITION ENERGY
      ↕
DISSIPATIVE / IRREVERSIBLE COMPONENT
```

A transformation can have a reversible component and an irreversible component. The branch must determine whether these are different manifestations of one quantity or genuinely different classes.

Therefore the current architecture is:

```text
                 ENERGY ?
                    │
          ┌─────────┴─────────┐
          │                   │
      STRUCTURAL           RELEASED
      / STORED              / ACTIVE
          │                   │
     potential            transition
          │                   │
          └─────────┬─────────┘
                    ↓
             relational change
```

# 4. Relation to the original hypothesis

Original formulation:

> **"Энергия — это следствие изменения связи в пространстве."**

The new hypothesis adds an important question:

> If energy is associated with relational change, is some energetic quantity already present in the relational configuration before the change occurs?

This creates a tension that must be tested rather than resolved philosophically:

### Version A

```text
relation
   ↓
change
   ↓
energy
```

Energy is primarily a consequence of change.

### Version B

```text
relation / structure
   ↓
stored potential
   ↓
change / restructuring
   ↓
release
```

Energy is already represented in the structure as potential, and change reveals/transfers it.

### Version C

```text
relation
   ↓
state configuration
   ↓
transition rule
   ↓
conserved quantity
```

"Stored" and "released" are only different observational descriptions of one underlying invariant.

All three remain OPEN.

# 5. Why destruction matters

A particularly important part of the hypothesis is the statement that **breaking a structure may require energy**.

This creates an experimental asymmetry worth testing.

If a structure is stable, changing it may require an input.

If a structure contains releasable potential, allowing it to move toward another configuration may produce an output.

Conceptually:

```text
BUILD / BIND
    ↑
    │ input
    │
[STRUCTURE]
    │
    │ release
    ↓
RECONFIGURATION
```

This suggests that the energetic property may belong not simply to an object but to a **configuration of relations**.

That is a stronger and more precise research direction than saying that "an object contains energy" without specifying what structural state is responsible.

# 6. Critical test: same elements, different structure

The first strong experiment should compare two systems containing the same elements but different relational configurations.

```text
System A:      A — B — C

System B:      A     B
                \   /
                  C
```

The exact graph is not yet fixed; it is only illustrative.

Question:

> If the elements are identical but the relations differ, does the model assign different transformation potentials?

If yes, that supports the idea that the energetic property belongs to **structure/configuration**, not merely to the elements themselves.

If no, the structural-energy hypothesis is weakened.

# 7. New experiments

## E-ENERGY-0010 — Structural potential

**Purpose:** test whether a static relation configuration can possess a measurable transformation potential before any transition occurs.

### Constraints

- no primitive variable named energy;
- no conventional potential-energy formula;
- identical elements across comparison cases;
- only relation/configuration differs.

### Procedure

1. Define two or more structurally distinct configurations.
2. Enumerate allowed local transformations.
3. Measure the transformation space available to each configuration.
4. Define candidate structural observables.
5. Test whether one observable predicts transformation cost, accessible state count, or release consistently.

### Primary question

> Does structure itself carry a measurable potential for change?

**Status:** PLANNED.

---

## E-ENERGY-0011 — Release test

**Purpose:** determine whether a structural potential becomes an observable during restructuring.

### Protocol

```text
S0 → S1 → S2
```

Measure the candidate structural quantity before, during, and after the transition.

### Prediction

If the hypothesis is useful, a change in structural potential should correlate with a measurable transfer or redistribution quantity.

### Falsification

If the candidate quantity has no predictive relationship to transition behaviour, it should not be retained as energy-like.

**Status:** BLOCKED until E-ENERGY-0010.

---

## E-ENERGY-0012 — Destruction / binding symmetry

**Purpose:** test whether creating and destroying a structural relation are energetically related in a reversible model.

Compare:

```text
A + B → A—B
```

and

```text
A—B → A + B
```

The question is not whether conventional chemistry says one direction requires energy. The question is whether a minimal relational model itself produces a corresponding asymmetry or conservation relation.

**Status:** BLOCKED until E-ENERGY-0010.

---

## E-ENERGY-0013 — Battery analogue

**Purpose:** test the user's "accumulator" intuition without importing a physical battery model.

Construct a system where repeated operations move the structure into a state with a larger set of accessible transitions or a larger measured transformation potential.

Then allow a controlled transition and determine whether the stored quantity decreases in a way that predicts the observed transformation.

Conceptual sequence:

```text
LOAD / BUILD
    ↓
STRUCTURAL STATE S_high
    ↓
HOLD
    ↓
RELEASE
    ↓
STRUCTURAL STATE S_low
```

The words `high` and `low` refer only to the candidate observable and must be defined quantitatively.

**Status:** BLOCKED until a candidate observable exists.

# 8. Most important falsification question

The strongest question is not:

> "Can we find energy in a changing structure?"

It is:

> **"Can we find a structure that has a measurable transformation potential even while it is not changing?"**

If the answer is yes, the original formulation "energy is a consequence of change" requires refinement.

A possible refined model would become:

> **Energy is a property of relational configuration that becomes observable as a consequence of allowed change.**

This is NOT a conclusion. It is the next hypothesis generated by the new observation.

```text

    ↓

    ↓

    ↓

```

### ORDER

ORDER records the provenance and sequence of the transition without assuming that update order is physical time.

```text

    ↓

    ↓

    ↓

```

These may eventually intersect, but Ω-Lab must not assume that memory, information, energy, and order are the same entity.
