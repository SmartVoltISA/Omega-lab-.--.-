# Ω-0 — Boundary / Reference Principle v1.0

## Status

**FOUNDATIONAL RESEARCH PRINCIPLE — RECORDED FROM Ω-LAB**

This document fixes the current formulation of the Ω-0 idea while preserving the historical distinction between observation, interpretation and hypothesis.

## 1. The zero point

`0` is treated here as a candidate **boundary / reference / neutral point** between opposing directions or states.

```text
        −1        |        +1
                  0
              boundary
              reference
```

The zero point is not a third opponent. It is the boundary from which deviation can be measured and at which interaction may occur.

## 2. Front of struggle / interaction

For a system containing opposing participants or tendencies:

```text
A  ←──────  0  ──────→  B
           ↑
       interaction
          front
```

The `0` point can therefore be interpreted as the **front of the current interaction or struggle**.

“Struggle” is not assumed universally. It is an interpretation applicable to models in which opposing processes compete or interact.

## 3. Zero is not absence

This principle must not be confused with the Ω-Math typed relation domain.

`RelationState = {−1,+1}`

and:

`absence of relation ≠ 0`

If no relation exists, there is no relation object. `0` must not be inserted as a fake third relation state merely to represent absence.

## 4. Zero as point of reference

If `0` is selected as the reference point, then `−1` and `+1` describe opposite deviations:

`−1 ← 0 → +1`

This gives a natural research chain:

`boundary → deviation → interaction → change → new boundary/reference`

which connects to the Ω feedback principle:

`boundary → deviation → check → feedback → correction → new stable state`

## 5. Time and path

If the boundary/front is indexed by time:

```text
t₀        t₁        t₂        t₃
 |         |         |         |
 0₀  →     0₁  →     0₂  →     0₃
```

then the ordered sequence describes the evolution of the interaction frontier.

This motivates the hypothesis:

> **A path can be understood dynamically as a time-ordered history of changing boundaries/fronts.**

The stronger phrase **“path is struggle through time”** is preserved as a useful interpretation for competitive dynamics, but is not declared the universal definition of path.

## 6. Research classification

**OBSERVATION:** Existing Ω-Lab work contains recurring analysis of zero, boundary, balance, transition and interaction.

**INTERPRETATION:** Zero may represent the frontier/reference separating or joining opposing processes.

**HYPOTHESIS:** Time evolution of that frontier may provide a compact description of a path and may connect boundary motion with dynamics, feedback and memory.

**STATUS:** OPEN / CANONICAL RESEARCH DIRECTION.

No claim of universal physical validity is made by this document.

## 7. Canonical formulation

> **Ω-0 Boundary / Reference Principle:** `0` is a candidate boundary, neutral reference, or interaction frontier between opposing states. It is not a third relational state and does not encode relation absence. The time-ordered evolution of the frontier provides a candidate dynamic interpretation of a path. In competitive models, this evolution may be interpreted as struggle through time.
