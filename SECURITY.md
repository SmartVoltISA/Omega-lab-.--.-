# SmartVolt Security Policy

## Scope

This repository is part of the SmartVoltISA project family.

## Reporting a vulnerability

Do not disclose credentials, tokens, private keys, personal data, or an exploitable vulnerability in a public issue. Use GitHub's private vulnerability reporting/security reporting mechanism when available. Otherwise contact the repository owner through a private GitHub channel.

## Secrets

Never commit API keys, passwords, access tokens, private keys, or secret-bearing .env files.

## Responsible disclosure

Provide enough information to reproduce and validate a security issue without exposing unnecessary sensitive data.

## History preservation

Security fixes should be committed normally. Do not rewrite or erase repository history without explicit authorization.
