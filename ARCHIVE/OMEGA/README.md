# OMEGA RESEARCH ARCHIVE

Research is separated from the SPACE implementation archive.

## THEORIES
Working conceptual models. They are not facts merely because they are recorded.

## HYPOTHESES
Explicitly testable claims with status: OPEN / TESTING / CONFIRMED / PARTIALLY_CONFIRMED / REFINED / REJECTED / NEEDS_RETEST.

## EXPERIMENTS
Protocols, preregistration, controls, seeds, code and execution records.

## CALCULATIONS
Derived quantities and computational notebooks/scripts, with inputs and assumptions.

## RESULTS
Observed outputs linked to the exact protocol/code revision.

## NEGATIVE
Failed, null and contradictory results are preserved and never hidden.

## Existing research remains authoritative at its original location

The repository already contains `Ω-INDEX`, `EXPERIMENTS`, `research/ARCHIVE`, `research/RELATIONS`, and multiple Ω-MEM/LINK experiment records. This directory is a navigation layer, not a destructive migration.

Example: Ω-MEM-G-1 is explicitly registered as an exploratory protocol and must not be treated as a physical claim before execution. Its existing protocol and hypothesis remain in their original locations.
