# Ω-LAB ARCHIVE

Purpose: a stable navigation layer over the historical repository. Existing history is preserved; this index does not replace or rewrite it.

## Zones

- `ARCHIVE/SPACE/` — SPACE organism, organs, tools, Guardian, graph, memory, stress and reports.
- `ARCHIVE/WORK/` — completed, current, next and blocked work.
- `ARCHIVE/OMEGA/` — theories, hypotheses, experiments, calculations, results and negative results.

## Rule

Every executable change must leave a trace containing:

1. date;
2. object/component;
3. input and conditions;
4. action;
5. checks performed;
6. result;
7. failures and boundary cases;
8. load/stress level;
9. dependencies and tools;
10. commit/reference;
11. next step.

Physical hardware tests are explicitly marked `PHYSICAL_REQUIRED` and are not claimed as verified by software-only CI.

## Preservation rule

Historical files are not deleted or silently rewritten. This archive is an index and operational record layer.
