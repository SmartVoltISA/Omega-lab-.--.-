# Ω — CORE RULE: ПОЛНАЯ ИСТОРИЯ

## Статус
Постоянное правило проекта Ω-Lab. Изменяется только по прямому решению владельца проекта.

## 1. История не удаляется
Любая гипотеза, эксперимент, расчёт, симуляция, результат, ошибка, неудачный метод и промежуточный вывод сохраняются.

## 2. Гипотезы не уничтожаются
Гипотеза получает статус: OPEN, TESTING, CONFIRMED, PARTIALLY_CONFIRMED, REJECTED или NEEDS_RETEST. Изменение статуса не удаляет предыдущую формулировку и связанные данные.

## 3. Опровержение — результат
Если эксперимент ломает гипотезу, она помечается REJECTED или уточняется. Сохраняются исходная формулировка, предположения, параметры, код, seed, данные, графики, вывод и причина изменения статуса.

## 4. Неудачные методы сохраняются
Если постановка эксперимента была неверной, критерий слабым, intervention настроен неправильно или метод дал ложный вывод, фиксируется: что сделали → почему не сработало → что изменили → что получилось.

## 5. Никакого переписывания истории
Правильная цепочка:

СТАРАЯ ВЕРСИЯ → ПРОВЕРКА → НОВЫЕ ДАННЫЕ → УТОЧНЕНИЕ → НОВЫЙ СТАТУС.

Новый результат не должен создавать видимость, будто предыдущего результата никогда не существовало.

## 6. Воспроизводимость
По возможности сохраняются дата, версия гипотезы, параметры, начальные условия, seed, код, сырые данные, графики, отчёт и итоговый статус.

## 7. Факт отделяется от интерпретации
- OBSERVATION — что непосредственно показала машина.
- INTERPRETATION — возможное объяснение.
- HYPOTHESIS — проверяемое предположение.
- EVIDENCE — подтверждающие данные.
- COUNTEREVIDENCE — данные против.

Интерпретация не выдаётся за факт.

## 8. Ошибки являются частью знания
Отрицательные результаты и сломанные гипотезы сохраняются, чтобы другие исследователи могли проверить их повторно и не повторять уже найденные ошибки.

## 9. Архитектура Ω
НАПРАВЛЕНИЕ → СВЯЗЬ → НАПРАВЛЕНИЕ → СВЯЗЬ → УЗЕЛ → СВЯЗЬ → УЗЕЛ → ГРАФ.

Графы могут пересекаться. Один эксперимент может быть связан с несколькими гипотезами, а одна гипотеза — с несколькими экспериментами.

## 10. Главное

НЕ УДАЛЯТЬ ИСТОРИЮ.
НЕ СКРЫВАТЬ ОШИБКИ.
НЕ ПОДГОНЯТЬ РЕЗУЛЬТАТ ПОД ГИПОТЕЗУ.
НЕ ВЫДАВАТЬ ИНТЕРПРЕТАЦИЮ ЗА ФАКТ.

Ω хранит весь путь:
ВОПРОС → ГИПОТЕЗА → ЭКСПЕРИМЕНТ → ОШИБКА → ИСПРАВЛЕНИЕ → ПРОВЕРКА → РЕЗУЛЬТАТ → СТАТУС → НОВЫЙ ВОПРОС.
