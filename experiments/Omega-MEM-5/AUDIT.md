# Ω-MEM-5 Preliminary Audit

**Status:** REVIEW REQUIRED

## What was executed

A local reference implementation matching the fixed Ω-MEM-5 protocol was executed with N=20,000, 10 seeds, S=4, five generators, and four memory conditions: none, relevant, mismatched, random.

## Robust observations

1. Periodic-4, Markov-2 and Thue-Morse show a large prediction improvement when memory preserves the generator-relevant context.
2. Equal nominal capacity with deliberately irrelevant/random memory does not reproduce that improvement.
3. IID does not benefit from the relevant-memory construction, providing a null control.
4. A single memory-state intervention changes the next prediction in the deterministic generators and in the HMM oracle-context check.

## Audit cautions

- The current runner is a reference implementation and must be reviewed against the frozen protocol before final acceptance.
- The HMM relevant-memory condition uses hidden state directly; this is an oracle-context test, not an observable-only predictor.
- Full per-seed raw data should be regenerated by the committed runner and archived before final interpretation.
- No claim is made that the result establishes a universal law of memory or choice.

## Current status

**PRELIMINARY POSITIVE / NOT YET FINAL**

The result supports the narrower computational hypothesis that functional predictive memory can depend on the structure of retained historical distinctions, not merely on nominal memory-state count. Final status awaits independent code/protocol audit and raw-data archival.
