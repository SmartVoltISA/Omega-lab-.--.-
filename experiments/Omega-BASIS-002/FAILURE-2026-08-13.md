# Ω-BASIS-002 — Execution Failure Record

Date: 2026-08-13
Status: **REJECTED / NO SCIENTIFIC RESULT CLAIMED**

## Why rejected

The preregistered execution was run twice with the same seed and produced byte-identical output. However, inspection of the executed model reveals that the planned falsification test is not adequate for the stated question.

The explicitly time-dependent M3 model changes its transition probability at the midpoint, but the fitted linear `state + t` model produced a time coefficient of only `-4.896906293412743e-06`, while the M2 stationary control produced `-2.06838515203666e-06`. The difference is not a preregistered statistical test and cannot establish that explicit time improves prediction.

More importantly, the current code uses a linear time trend as the only representation of nonstationarity. A midpoint change in transition probability is not equivalent to a linear drift, so failure/success of that coefficient is not a valid test of the hypothesis.

The code also emitted a NumPy deprecation warning from converting an array to a scalar. The run completed, but this warning means the implementation should be cleaned before validation.

## Decision

The experiment is **FAILED AS A TEST**, not a failed hypothesis.

No claim is made that time is or is not a state component.

A corrected replication must compare predictive models that can represent the known piecewise transition structure, use out-of-sample evaluation, and test whether adding time/history materially improves prediction beyond the declared state.

This is exactly the Ω-Lab rule: a flawed test must be rejected rather than interpreted to fit the hypothesis.
