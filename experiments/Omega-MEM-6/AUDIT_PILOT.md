# Ω-MEM-6 Pilot — Audit

## What is supported

- The pilot was independently recomputed from the committed executable logic before recording these values.
- Relevant memory reduces conditional next-transition entropy for the tested deterministic generators.
- Random/irrelevant memory does not provide the same reduction.
- IID control shows no meaningful predictive benefit.

## What is NOT established

- No universal law of memory has been established.
- No causal claim is made from the pilot alone.
- No claim about agency, free choice, consciousness, or physical systems is made.
- The pilot does not yet quantify the full predictive partition or number of distinguishable future transitions.

## Required next validation

1. multiple independent seeds;
2. equal-capacity matched architectures;
3. explicit predictive partition size and entropy;
4. memory-only intervention while holding current observation fixed;
5. per-seed raw data and confidence intervals;
6. independent audit before interpretation.
