# Ω-MEM-8 — Path Trace Memory

**Status:** OPEN / protocol definition only
**Date:** 2026-08-14
**Relation:** continuation of Ω-MEM-7; removes direct next-transition encoding from memory.

## Question

Can a memory that stores only a trace of the preceding path affect the distinguishability and uncertainty of future transitions, without directly encoding the identity of the next transition?

## Core hypothesis

A system may carry information about its history in a state-like memory trace. If that trace changes the conditional distribution of future transitions after the current observable state is held fixed, then memory has predictive causal relevance beyond the current observable state.

## Critical design constraint

The memory representation MUST NOT contain a direct label, index, or lookup key for the next transition. The next transition must be generated by the system dynamics from the current state plus the path-dependent internal state.

## Conditions

Use matched-capacity memory across:

1. **Path-trace memory** — stores a deterministic trace derived only from prior transitions.
2. **Capacity-matched irrelevant memory** — same nominal state capacity, but independently permuted relative to the process.
3. **Reset intervention** — replace only the internal memory trace while preserving the current observable state.

Use deterministic processes with controlled branching and at least one stochastic/null process.

## Measurements

Record:

- `H(next | current)`;
- `H(next | current, memory)`;
- `I(next; memory | current)`;
- empirical next-transition distribution;
- number of distinguishable future transitions;
- intervention effect after memory reset;
- recovery dynamics after reset.

## Falsification

The hypothesis is weakened if path-trace memory is indistinguishable from irrelevant memory at matched capacity, or if resetting memory while holding the current observable state fixed does not alter subsequent transition statistics where the dynamics predict history dependence.

## Controls

- Equal memory capacity.
- Equal sequence length and seed count.
- Same current-state distribution across intervention/control conditions.
- No direct future-transition labels in memory.
- Explicit verification of memory contents before every run.
- Separate audit of the generator to confirm that future labels are not injected into memory.

## Non-claims

This experiment does not test consciousness, agency, free will, or whether choice is fundamental. It tests only whether a path-derived internal trace has measurable predictive/causal relevance for future transitions.

## Freeze rule

This protocol is frozen before implementation. Any correction must be recorded as an amendment and must not silently change the primary test.
