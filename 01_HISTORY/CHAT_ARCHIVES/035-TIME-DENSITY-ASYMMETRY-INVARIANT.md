# 4. Ω-X — проверка C и I

Рассматривались две возможные вторичные основы после различия D:

- C — coexistence;
- I — iterability.

Экспериментальная постановка:

### M₁
`D + C → ? I`

### M₂
`D + I → ? C`

Возможные результаты:

| Результат | Интерпретация |
|---|---|
| C ⇒ I и I ⇒ C | один объединённый второй примитив |
| C ⇒ I, I ⇏ C | C фундаментальнее |
| I ⇒ C, C ⇏ I | I фундаментальнее |
| ни одно не следует | два независимых свойства |

Статус: **PROPOSED / UNRESOLVED**.

# 6. Whole ↔ Different

Рабочая циклическая схема:

`целое → различение → отношения → интеграция → новое целое`

и обратно:

`целое ← различия`.

Это рассматривается как потенциально универсальный организационный мотив, но универсальность не доказана.

# 8. Порядок ≠ время

Зафиксировано различие:

- порядок/иерархия может быть статической структурой;
- время требует дополнительного свойства — изменения, сравнения, направленности, распространения или иного механизма.

Контрпримеры:

- файловая система;
- рейтинг;
- статическая иерархия.

Они имеют порядок, но не дают автоматически физического времени.

Статус: **METHODOLOGICAL CONSTRAINT**.

---

# 9. Графовая модель и скрытая динамика

Рассматривался граф:

`A—B—C—D`

с добавленным ребром:

`A—C`.

Была предложена модель удаления узлов для получения ранга/«времени».

Критика:

> удаление узлов — операция, а операция уже вводит последовательность.

Следовательно, модель не доказывает происхождение времени из статической структуры.

Статус: **REJECTED AS PROOF / USEFUL CRASH TEST**.

# 10. Спектральная модель

Использовались:

- adjacency matrix A;
- eigenvalues λᵢ;
- eigenvectors v;
- λmax;
- производная:

`∂λmax / ∂Aij = vi vj`.

Для указанного графа сообщались приблизительные значения:

`λmax ≈ 2.17`

и структурный порядок:

`D ≺ (A ~ B) ≺ C`.

Ключевой вывод критики:

> спектральный ранг может дать **структурный порядок**, но порядок не равен времени.

Статус: **CONCEPTUAL RESULT / NOT TIME**.

# 11. Isospectral crash test

Была предложена проверка на графах с одинаковым спектром Лапласиана.

Идея:

> если спектр одинаков, но структуры различны, спектр сам по себе недостаточен как универсальный носитель структуры/времени.

Статус: **CRASH TEST / REPORTED, NOT INDEPENDENTLY VERIFIED**.

# 12. Diffusion / influence asymmetry

Использовалась модель:

`L = D − A`

и diffusion kernel:

`K(τ) = exp(−τL)`.

Спектральная форма:

`K(τ) = Σ exp(−τλₖ) φₖ φₖᵀ`.

Сравнивались:

- uniform network;
- clustered network.

Мера асимметрии:

`Δij = Kij − Kji`.

Сообщённые результаты:

- uniform mean asymmetry ≈ 0.01;
- clustered mean asymmetry ≈ 0.08.

Также определялся node flow:

`Flow(i) = Σj (Kij − Kji)`.

Интерпретация источника: кластерная структура даёт более выраженную асимметрию влияния.

Но критическая проблема:

> `τ` математически является параметром эволюции/распространения, даже если назвать его «масштабом».

Поэтому эксперимент не доказывает возникновение времени из полностью статической структуры.

Статус: **REPORTED RESULT / NOT PROOF OF TIME**.

# 15. Инвариант как новый мета-вопрос

Вместо поиска ещё одной сущности появляется вопрос:

- структура;
- закон;
- правило преобразования;

Статус: **OPEN / CURRENT META-PROBLEM**.

# 16. Путь / площадь / время

В финальной части архива появляется гипотеза:

> путь может быть выражением времени;
> площадь может быть выражением времени.

Более нейтральная формулировка:

> время может быть не независимой координатой, а мерой накопленного изменения/пути/структурной перестройки.

Кандидаты для сравнения:

- path length;
- number of links;
- density;
- area;
- entropy.

Статус: **OPEN / UNTESTED**.

# 17. Ключевые контраргументы

1. Статический порядок не является временем.
2. Удаление узлов вводит последовательность.
3. Спектральная структура не гарантирует динамического потока.
4. Diffusion kernel уже содержит эволюционный параметр τ.
5. Спектр может не различать все структуры.
6. Плотность не доказано порождает асимметрию.
7. Асимметрия не доказано порождает направление.
8. Направление не доказано тождественно времени.
9. Путь/площадь могут быть просто коррелятами времени, а не его основанием.
