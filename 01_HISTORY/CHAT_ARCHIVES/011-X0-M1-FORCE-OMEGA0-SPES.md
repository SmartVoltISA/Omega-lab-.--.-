# Архив 011 — X-0 / M1 / Force / Ω-0 / Спес

Источник: OMEGA_CHAT_FULL_ARCHIVE-10.md
Статус источника: реконструировано из доступного контекста.

## Суть направления

Развитие Ω-Lab от ранних моделей M0–M3 и Ω-B к X-0.M1: поиск устойчивой структуры, возникающей из локальных отношений без заранее заданных объектов, пространства, времени и внешнего управления.

## Ранние основания

M0–M3: периодический ABCD, случайность, глобальная память, локальная память. Метрики: энтропия, автокорреляция, Lempel-Ziv complexity, modularity, Hurst exponent.

Ранние результаты из архива: N=100, p=0.3, 1000 запусков — заявлен 100% collapse; hysteresis T=0.3 и разделение временных масштабов — снова заявлен 100% collapse; модель только рёбер — Attractor 15 (7.5%), Collapse 0, Cycle 185 (92.5%), среднее до аттрактора 632.3 ± 298.2.

## Ω-B

Конкурирующие потенциалы: `w+`, `w-`, `w = w+ - w-`, `B = |dw+/dt| + |dw-/dt|`. Исследовались 1000 узлов, случайные связи, сила 0..1, параллельные случайные блуждания, параметры α/β. Архив фиксирует влияние β на режимы и существование кластеров/плато.

## X-0.M1

Цель: исследовать, может ли структура возникать из локальных отношений без пространства, времени, объектов и внешнего управления.

Состояния отношений: `{-1,0,+1}`. Локальный баланс и правило `F(s,b)`.

Заявлено: 43 класса правил порождают структуру; 22 сохраняют структуру во всех режимах; после усиленной проверки выделено 16 ядерных классов.

Обнаруженные дубликаты в выборке E-01...E-20 привели к новой генерации выборки с полной сигнатурой и заменой дубликатов. После этого вычислительная исследовательская программа была отделена от аналитического прогноза.

## X-0.M1.V — усиленная верификация

Заявленные проверки:
- Python → Go, N=6, K=3, 500 шагов, 5 начальных конфигураций: 22/22 подтверждений;
- масштабирование N=4,5,6,7,8,10,12: 18,20,22,22,21,19,16 классов;
- чувствительность K=2 → 0/22; K=4 → 20/22; K=5 → 18/22; 1000 шагов → 22/22; новые условия → 21/22; дополнительные режимы → 20/22.

Инвариант I:
`b=0 → F(s,0)=0`; `b>0 → F(s,b)≠-1`; `b<0 → F(s,b)≠+1`.

Граница устойчивости: 16 ядерных классов требуют минимум 3 изменений переходов для разрушения; 6 периферийных могут разрушаться одним изменением; особенно чувствительна позиция `(s=0,b=0)`.

Полный перебор 1847 классов: 47 удовлетворяют I; 1800 — нет. Для 47 заявлены 43 устойчивая структура, 22 во всех режимах, 16 ядро, 4 collapse, 0 периодика, 0 хаос. Для 1800 без I: 1711 collapse, 216 периодика, 94 chaos, 0 stable structure, 79 unclassified.

Асимметрия A: существует `s,b: F(s,b) != F(s,-b)`.

Осторожная формулировка архива: `I ∧ A` является необходимым, но не достаточным условием в исследованном пространстве.

## M1.2 — сила

Ключевая формулировка пользователя: **«сила — память отношений»**.

Сначала сила не задаётся извне, а измеряется как возникающая характеристика.

Измерялись возраст, частота изменений, влияние, согласованность, центральность, стабильность кластера. Заявлены различия устойчивых и периферийных отношений; возраст+согласованность+центральность давали F1 около 0.95 в одном варианте.

Лучшая заявленная форма на одном этапе: `p = возраст × (согласованность + 0.3)`. При автоматическом поиске на обучении: `p = возраст × (согласованность + 0.25)`; заявленные F1: обучение 0.95, N=10,12 0.93, новые условия 0.94, новый режим 0.92, всё вместе 0.91; на пяти новых классах 4/5 успешно.

## M1.2.1 — статическая сила

Режимы A–D: без силы, естественная сила, случайная сила, перемешанная сила. Заявлены устойчивость 87%, 94%, 83%, 85% соответственно; естественная сила дала лучшее восстановление/стабилизацию. Для симметричных классов собственная сила давала устойчивость, чужая — collapse.

Вывод: конкретная форма силы не является уникальной; сила специфична для динамики правила.

## M1.2.2 — динамическая сила

Локальные правила изменения силы используют текущую силу, знак, возраст, локальный баланс, согласованность; запрещены глобальные переменные, внешние параметры, будущие состояния и данные других классов.

Успешные примеры: E-07 `Δp=α·a·c`; E-12 `Δp=α·a+β·c`; D-05 `Δp=α·B`; F-03 `Δp=α·min(a,c)`. Заявленные корреляции с распределениями M1.2.1: 0.89, 0.85, 0.62, 0.78.

## Усиление различия и область устойчивости

100 правил, усиливающих различие: 83 дали структуру, 17 нет; 100 правил без усиления различий: 0 устойчивых структур. Осторожное обновление: усиление различий необходимо, но недостаточно.

Для E-07 изменение λ от 0 до 2 дало заявленную область устойчивости примерно `[0.1,1.0]`, оптимум около 0.5–0.6; большие λ разрушают структуру. Для других правил диапазоны также конечны.

Введён локальный `λ_i` и семейства R1–R5. Заявлено, что успешные правила удерживают λ в рабочем диапазоне, особенно комбинации R4. Гипотеза: локальная саморегуляция способна удерживать систему в области устойчивости.

## Сила как энергия

E1–E6: заявлены корреляция сила↔влияние `r=0.83`, p<0.001; изменение силы соседей в 72% случаев, направленный перенос 34%; `P_total=Σp_i` растёт к плато около `0.45*N_relations`; потоки ядро→периферия 0.12, периферия→ядро 0.08, циркуляция внутри ядра 0.34; локальный импульс затухает на расстоянии 4–5; работа возрастает с силой, `r=0.79`.

Осторожный итог: гипотеза «сила как энергия» не была опровергнута по некоторым тестам, но ослаблена по дальнему переносу и потокам.

## Ядро как аккумулятор / локальный накопитель

N1–N10 описывают рост силы ядра, восстановление после возмущений, связь высокой силы ядра с восстановлением периферии, истощение ядра при последовательных возмущениях, почти независимое поведение локально разделённых ядер, одностороннюю подпитку, замороженное ядро и удаление старого ядра с формированием нового.

Заявлено: после удаления старого ядра новое ядро имеет размер около 26%, силу около 0.87 и пересечение состава 62%. Рабочая гипотеза: ядро — возникающее свойство динамики.

## Методология

Главный принцип: **«Не искать подтверждение. Искать способы разрушить найденное.»**

Кандидаты: `I ∧ A`, усиление различия, область устойчивости, саморегуляция, ядро как локальный накопитель, саморазделение структуры. Ни один не объявлен окончательным законом.

## Ω-0

Ω-0 описывается как онтологически нейтральный полигон: без объектов, узлов, графа, пространства, внешнего времени, памяти как отдельного хранилища и заранее заданной композиции.

Первичны `-1,0,+1`. Ноль трактуется как активная граница.

Среда может хранить текущее состояние, порождать отношение, сравнивать, оставлять след через изменение функции перехода, фиксировать устойчивость и эволюционировать.

Главный вопрос: может ли из взаимодействия возникнуть порядок, затем структура, граф, пространство или память? Ограничение архива: пока нет полноценного второго независимого процесса для взаимодействия.

## ИИ и разделение Ω / Спес

Поставлена цель создать ИИ на основе среды, а внутри среды — сознание, память и необходимое для работы.

Важная архитектура:

`Пользователь → Спес → Ω → результат → Спес → Пользователь`.

**Ω** — чистая вычислительная среда; не хранит долговременную память пользователя; каждый запрос получает отдельный вычислительный мир; после расчёта состояние уничтожается.

**Спес** — долговременная память, история, знания, пользовательский контекст, интерпретация и общение.

Также обсуждался предметный интерпретатор:
`данные → Ω → математический результат → интерпретатор → человеческий отчёт`.

## Ключевые идеи архива

1. Структура может возникать из локальных отношений.
2. Сравнение и локальный баланс выступают базовыми механизмами исследуемой модели.
3. Сила может быть рассматриваема как память отношений.
4. Сила может быть возникающей характеристикой, а не заданной константой.
5. Устойчивость имеет конечную область; чрезмерное усиление может разрушать структуру.
6. Саморегуляция может быть локальной.
7. Ядро может быть возникающим центром устойчивости и накопления.
8. Ω-0 должна быть максимально минимальной вычислительной средой.
9. Долговременная память должна находиться вне чистого вычислительного ядра Ω.
