## Ω-MEM-4R core results

- Periodic-4: matched architecture reached 1.000 at valid S; Counter reached 1.000 at S=4.
- Markov-2: Context-1/2/3 and matched ≈0.823; the tested generator's last-symbol partition was sufficient.
- Thue-Morse: tested matched representation remained ≈0.50 while Random S=64 reached ≈0.730; this is a counterexample to the tested representation, not proof that random memory is intrinsically superior.
- HMM: matched ≈0.70; entropy decreased with S without corresponding accuracy gain.
- Random-iid: architectures remained ≈0.50; negative control passed.

## Methodological history

Ω-MEM-4 contained protocol/design problems. Ω-MEM-4R preserved those errors and corrected them through validation, equal-capacity comparisons where valid, random ensembles, true Context-2/3 shift registers, stronger process definitions, intervention/recovery checks and raw per-seed reporting.

The first Context-2 validation failure was due to an incorrect expected-value test. The expected state sequence was corrected and validation then passed. This correction is preserved as part of the historical record.
