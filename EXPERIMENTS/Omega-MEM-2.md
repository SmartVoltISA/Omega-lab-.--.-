# Ω-MEM-2 — Memory → Prediction

**Status:** SPECIFICATION / OPEN

## Цель

Проверить, является ли память не просто состоянием, которое может причинно менять траекторию после intervention, а функциональным механизмом, дающим системе преимущество в предсказании следующего акта.

Ключевой вопрос:

> Может ли минимальная память предсказывать следующий акт лучше системы без памяти, и что именно ей необходимо сохранять для этого?

## Связь с предыдущими результатами

Ω-0 показал, что обновляемый след создаёт внутренне различимый порядок в минимальной модели.

Ω-MEM-1a–1d уточнил причинность памяти:

- S=1: causal effect структурно невозможен;
- S≥2: causal effect возможен, но не гарантирован;
- structured и random memory имеют разные trade-off между частотой срабатывания и силой эффекта;
- размер регистра сам по себе не равен функциональности памяти.

Следующий шаг — проверить не только causal effect, но и **prediction advantage**.

## Основная гипотеза H-0.7

> Память может функционировать как хранение связи между состояниями, а не как простое хранение предыдущего состояния.

Гипотеза открытая и не считается подтверждённой.

## Экспериментальная схема

Сравнить минимум четыре класса машин:

- **M0 — без памяти:** следующий акт определяется только текущим входом;
- **M1 — state memory:** хранится только последнее состояние;
- **M2 — relation memory:** хранится отношение / переход между предыдущим и текущим состоянием;
- **M3 — randomized control:** память такого же размера, но структура переходов случайно переставлена.

Не вводить произвольные веса, вероятности или коэффициенты без отдельного обоснования.

## Ключевой контроль

Одинаковый текущий вход должен подаваться машинам после разных историй.

Для каждой истории измеряется:

1. правильность предсказания следующего акта;
2. prediction advantage относительно M0;
3. сколько информации памяти реально необходимо;
4. что происходит после causal reset памяти;
5. сохраняется ли преимущество после удаления абсолютного состояния и оставления только отношения.

## Intervention test

Для каждой машины создать две копии одной и той же истории:

A — память сохраняется;
B — память сбрасывается непосредственно перед одинаковым следующим входом.

Измерить различие будущих выходов.

Важно: intervention должен быть проведён на одной и той же истории, а состояние памяти в момент сброса должно быть явно зафиксировано.

## Null controls

Обязательно проверить:

- случайную память того же размера;
- перемешивание отношений при сохранении распределения;
- одинаковое число возможных состояний;
- одинаковый набор входов;
- одинаковые начальные условия там, где это применимо.

## Критерий интересного результата

Результат считается интересным только если:

1. prediction advantage воспроизводится на независимых историях;
2. он исчезает или существенно уменьшается после разрушения структуры памяти;
3. преимущество не объясняется просто большим объёмом состояния;
4. результат сохраняется против random/null controls.

## Возможные исходы

### A — подтверждение
Relation memory даёт устойчивое преимущество над state-only и random controls.

### B — частичное подтверждение
Преимущество появляется, но объясняется более простой особенностью архитектуры.

### C — опровержение
Relation memory не даёт преимущества после честных контролей.

### D — новый вопрос
Prediction advantage зависит не от размера памяти, а от определённого класса структуры переходов.

## Правило истории

Никакие отрицательные результаты не удаляются.
Если эксперимент сломает H-0.7, гипотеза получает статус REJECTED, но этот файл и все данные эксперимента остаются в архиве.
