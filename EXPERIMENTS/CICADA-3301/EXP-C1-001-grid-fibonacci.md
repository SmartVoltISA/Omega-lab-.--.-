# EXP-C1-001 — 3301 Grid → Prime Index → Fibonacci

**Status:** PROVED (local arithmetic property)
**Date:** 2026-08-28
**Branch:** `research/cicada-3301`

## Question

Is the reported 4×4 number-grid relation actually exact, or is it a loose pattern selected after the fact?

## Input

Reported grid:

```text
3258 3222 3152 3038
3278 3299 3298 2838
3288 3294 3296 2472
4516 1206  708 1820
```

The community analysis reports using `3301 - x` for the first 12 entries and `x - 3301` for the final four entries.

## Reproduction

Absolute differences from 3301:

```text
43   79   149  263
23   2    3    463
13   7    5    829
1215 2095 2593 1481
```

However, the source reconstruction that yields the claimed prime/Fibonacci relation uses the signed values 7817 and 4507 for the first two bottom-row entries, i.e. effectively `3301 + 4516` and `3301 + 1206`, not the literal positive grid values above. Therefore the exact sign convention must be recovered from the original image before treating the full grid as a proven object.

Using the reported signed construction:

```text
43   79   149  263
23   2    3    463
13   7    5    829
7817 4507 2593 1481
```

all 16 numbers are prime.

Their zero-indexed prime ordinals are:

```text
13  21  34  55
8   0   1   89
5   3   2   144
987 610 377 233
```

These are exactly the first 16 Fibonacci numbers (with F0=0, F1=1), arranged spatially.

## Result

**PROVED:** Given the reported signed grid, the prime test and Fibonacci-index mapping are exact arithmetic facts. The resulting spatial arrangement therefore contains a deterministic Fibonacci ordering.

**NOT PROVED:** that this mechanism was intentionally placed by Cicada, because the sign convention for the bottom-left two cells must first be checked against the primary page image, and the interpretation "therefore spiral path" is an additional hypothesis.
